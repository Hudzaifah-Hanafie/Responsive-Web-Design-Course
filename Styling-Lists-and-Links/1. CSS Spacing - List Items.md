# CSS Spacing: List Items (`margin` vs. `line-height`)

When styling list items (`<li>`), controlling vertical space improves visual hierarchy and readability. Two common CSS properties used for spacing are `margin` and `line-height`, but they operate on completely different layout principles.

---

## 1. Baseline HTML List

By default, browser stylesheets apply minimal vertical spacing between `<li>` elements, creating a compact vertical stack.

```html
<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```

To increase space between these items, we need to choose between adjusting **external margins** or **internal line height**.

---

## 2. Spacing List Items with `margin`

### Core Concept
The `margin-bottom` property adds space **outside** the boundary of each list item. This creates true separation between individual items without altering font proportions or internal text spacing.

### Why It Matters
* **Predictable Layout:** Works consistently regardless of how many lines of text a list item contains.
* **Clean Separation:** Directly targets item-to-item distance without side effects.

### Example

**HTML:**
```html
<link rel="stylesheet" href="styles.css">

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```

**CSS:**
```css
li {
  margin-bottom: 40px;
}
```

### Explanation
In this example, every `<li>` receives `40px` of outer space beneath it. This pushes subsequent `<li>` elements down, creating a clean gap between separate list items.

---

## 3. Spacing List Items with `line-height`

### Core Concept
The `line-height` property controls the vertical height of text lines **within** an element.

### Why It Can Be Misleading
If a list item contains only **a single line of text**, increasing `line-height` expands the height of the line box, which visually looks like space was added between list items.

However, if a list item wraps across **multiple lines**, `line-height` expands the space *between lines of text inside that same item*, rather than just between separate list items.

### Example

**HTML:**
```html
<link rel="stylesheet" href="styles.css">

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```

**CSS:**
```css
li {
  line-height: 2; /* 200% of the font size */
}
```

> [!WARNING] The Multi-line Catch
> `line-height: 2;` doubles the height of line boxes within the item. If "Item 1" wraps into two lines, the gap between line 1 and line 2 of "Item 1" will also double, which is usually not what you want.

---

## 4. Comparison

| Feature | `margin-bottom` | `line-height` |
| :--- | :--- | :--- |
| **Space Location** | Outside the element (external) | Inside the element (text line box) |
| **Primary Purpose** | Element-to-element separation | Text line spacing / typography |
| **Multi-line Behavior** | Keeps internal text compact, spaces items apart | Spreads apart lines of text *within* the item |
| **Best Practice** | **Recommended** for list item gaps | **Avoid** as a substitute for spacing items |

---

## Mental Model

Think of a list item as a **box with text inside**:

```text
┌───────────────────────────────┐
│  List Item 1                  │  <-- line-height controls space between text lines inside
│  (Second line of text)        │
└───────────────────────────────┘
                ↕  <-- margin-bottom controls space between separate boxes
┌───────────────────────────────┐
│  List Item 2                  │
└───────────────────────────────┘
```

* **`margin-bottom`** pushes the next box down.
* **`line-height`** expands the height of text lines inside the box.

---

## Key Takeaways

* **Use `margin`** (or `margin-bottom`) to create space between separate list items.
* **Use `line-height`** exclusively for typographical adjustments to text readability.
* **Avoid `line-height` for layout gaps**, as multi-line list items will break visually.
