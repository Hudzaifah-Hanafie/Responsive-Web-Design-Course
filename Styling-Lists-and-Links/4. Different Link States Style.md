# How Do You Style the Different Link States?

Links can have different **interaction states**, such as whether they are unvisited, visited, being hovered over, focused, or actively being clicked.

CSS provides **pseudo-classes** that let you style an element differently depending on its current state. For links, the most important states are:

- `:link` — an **unvisited** link.
- `:visited` — a link the user has **already visited**.
- `:hover` — a link the user's pointer is **hovering over**.
- `:focus` — a link that currently has **keyboard or other focus**.
- `:active` — a link that is **currently being clicked/activated**.

Using distinct styles for these states gives users visual feedback about what is happening and makes navigation easier to understand.

> **Why it matters:** Clear link states improve usability and accessibility by helping users recognize links, understand their current interaction, and keep track of links they have already visited.

---

## 1. CSS Pseudo-Classes

A **pseudo-class** is a keyword added to a CSS selector that targets an element based on a particular state or condition.

For example:

- `:hover` can change an element's appearance when the pointer is over it.
- `:visited` can change the appearance of a link that has already been visited.

Pseudo-classes are useful because they let you style elements according to their state or user interaction **without adding extra HTML markup**.

### Basic Syntax

A pseudo-class is written after a selector:

```css
A:B {
  property: value;
}
```

Where:

- `A` is the CSS selector.
- `:B` is the pseudo-class.
- `property: value;` is the style applied when the element matches that state.

For example:

```css
a:hover {
  color: green;
}
```

This targets an `<a>` element while the user's pointer is hovering over it.

---

## 2. The `:link` State

The `:link` pseudo-class styles **unvisited links**.

This can be used to give users a visual indication of the normal appearance of a link they have not visited yet.

### Example

HTML:

```html
<link rel="stylesheet" href="styles.css">

<a href="/">Example link</a>
```

CSS:

```css
/* Normal state (unvisited link) */
a:link {
  color: red;
}
```

In this example, an unvisited link will be displayed in `red` instead of its default blue color.

### Key Idea

```text
:link → unvisited link
```

---

## 3. The `:visited` State

The `:visited` pseudo-class styles links that the user has **already visited**.

This helps users distinguish links they have previously clicked or visited from links they have not visited.

### Example

HTML:

```html
<link rel="stylesheet" href="styles.css">

<a href="https://www.freecodecamp.org/learn/" target="_blank">freeCodeCamp</a>
```

CSS:

```css
/* Visited link */
a:visited {
  color: green;
}
```

After the link has been visited, it will be displayed in `green`.

### Key Idea

```text
:visited → previously visited link
```

---

## 4. The `:hover` State

The `:hover` pseudo-class styles a link while the user's **pointer is hovering over it**.

This provides immediate visual feedback that the element is interactive.

### Example

HTML:

```html
<link rel="stylesheet" href="styles.css">

<a href="/">Example link</a>
```

CSS:

```css
/* Hover state */
a:hover {
  color: green;
}
```

When the mouse pointer is placed over the link, its color changes to `green`.

### Key Idea

```text
:hover → pointer is over the link
```

---

## 5. The `:focus` State

The `:focus` pseudo-class styles a link when it **has focus**.

Focus is especially important for accessibility because users can navigate links using a keyboard rather than a mouse.

One common way to make the focused link easier to see is to add an `outline`.

### Example

HTML:

```html
<link rel="stylesheet" href="styles.css">

<a href="/">Example link</a>
```

CSS:

```css
/* Focus state */
a:focus {
  outline: 2px solid orange;
}
```

When the link receives focus, a solid orange outline appears around it.

### Why It Matters

A visible focus style helps users identify **which element they are currently interacting with**, particularly when navigating with a keyboard.

### Key Idea

```text
:focus → link currently has focus
```

---

## 6. The `:active` State

The `:active` pseudo-class styles a link while it is **being activated or clicked**.

It provides immediate visual feedback that the user's action is being registered.

### Example

HTML:

```html
<link rel="stylesheet" href="styles.css">

<a href="/">Example link</a>
```

CSS:

```css
/* Active state */
a:active {
  color: pink;
}
```

While the link is being clicked, its color changes to `pink`.

### Key Idea

```text
:active → link is currently being clicked/activated
```

---

## 7. Comparing the Link States

| Pseudo-class | Link state | What it indicates |
|---|---|---|
| `:link` | Unvisited | The user has not visited the link yet |
| `:visited` | Visited | The user has already visited the link |
| `:hover` | Hovered | The pointer is currently over the link |
| `:focus` | Focused | The link currently has focus |
| `:active` | Active | The link is currently being activated/clicked |

These states can overlap depending on what the user is doing. For example, a link can be visited and also hovered at the same time.

---

## 8. Why Link States Matter

Different link states provide **visual cues** that help users understand the interface.

They can help users:

- Recognize which elements are links.
- Tell whether they have already visited a link.
- See which link they are currently interacting with.
- Receive immediate feedback when activating a link.
- Navigate a page more easily using a keyboard.
- Reduce confusion when moving through a website.

Distinct link states can be particularly helpful for users with **visual impairments or cognitive disabilities**, because consistent visual feedback can make navigation more understandable.

> **Important:** Link styling is not only about appearance. It also communicates the current state of an interaction to the user.

---

## 9. Mental Model

A simple way to remember the five main link states is to think about what is happening to the link over time:

```text
                    ┌─────────────────┐
                    │     :link       │
                    │   Unvisited     │
                    └────────┬────────┘
                             │
                             │ User visits link
                             ▼
                    ┌─────────────────┐
                    │    :visited     │
                    │     Visited     │
                    └─────────────────┘

        Pointer moves over link
                    │
                    ▼
              ┌───────────┐
              │  :hover   │
              │  Hovered  │
              └───────────┘

        Link receives focus
                    │
                    ▼
              ┌───────────┐
              │  :focus   │
              │  Focused  │
              └───────────┘

        User activates link
                    │
                    ▼
              ┌───────────┐
              │  :active  │
              │  Active   │
              └───────────┘
```

The important distinction is that these pseudo-classes describe **different conditions**, rather than being five permanent stages that every link must pass through in a fixed order.

---

## Summary

CSS pseudo-classes allow you to style links according to their current state or the user's interaction with them.

| State | Pseudo-class | Main purpose |
|---|---|---|
| Unvisited | `:link` | Style links the user has not visited |
| Visited | `:visited` | Style links the user has already visited |
| Hover | `:hover` | Give feedback when the pointer is over the link |
| Focus | `:focus` | Show which link currently has focus |
| Active | `:active` | Give feedback while the link is being activated |

### Key Takeaways

- **Pseudo-classes** let CSS respond to an element's state or user interaction.
- `:link` targets **unvisited** links.
- `:visited` targets **visited** links.
- `:hover` targets links while the **pointer is over them**.
- `:focus` targets links that **currently have focus** and is important for keyboard accessibility.
- `:active` targets links while they are **being activated/clicked**.
- Distinct link states provide useful **visual feedback**, improving usability and accessibility.
