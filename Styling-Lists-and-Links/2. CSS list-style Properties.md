# How Do the Different `list-style` Properties Work?

CSS provides several properties for controlling the appearance of lists. The `list-style` property is especially useful because it lets you customize **what the list marker looks like**, **where it is positioned**, and **whether an image is used as the marker**.

This applies to both:

- Ordered lists: `<ol>`
- Unordered lists: `<ul>`

The `list-style` property is a **shorthand property** for three individual properties:

| Property | Controls |
|---|---|
| `list-style-type` | The type of bullet or numbering |
| `list-style-position` | Where the marker is positioned relative to the list item's content |
| `list-style-image` | An image used as the list marker |

A useful way to remember them is:

> **Type = what the marker looks like**  
> **Position = where the marker goes**  
> **Image = whether an image is used as the marker**

---

## 1. `list-style-type`

The `list-style-type` property controls the **type of marker** displayed for each list item.

### Unordered Lists

For an unordered list (`<ul>`), you can choose different bullet styles, including:

- `disc`
- `circle`
- `square`

For example:

```html
<ul style="list-style-type: square;">
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```

Here, the normal bullet markers are changed to **square markers**.

### Ordered Lists

For an ordered list (`<ol>`), `list-style-type` can also control the numbering system.

For example, ordered lists can use styles such as:

- Decimal numbers
- Roman numerals
- Alphabetical characters

### Why It Matters

`list-style-type` is often the most noticeable of the three properties because it directly changes the **bullet or numbering style** of the list.

---

## 2. `list-style-position`

The `list-style-position` property controls **where the list marker is positioned in relation to the list item's content**.

It has two main values:

- `outside`
- `inside`

### `outside`

With `outside`, the marker appears **outside the main content area** of the list item.

This is the default behavior.

### `inside`

With `inside`, the marker is placed **inside the content area** of the list item.

This can affect how the text wraps and aligns, particularly when a list item contains multiple lines of text.

### Example

```html
<ul style="list-style-position: inside;">
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>

<ul style="list-style-position: outside;">
  <li>Item 4</li>
  <li>Item 5</li>
  <li>Item 6</li>
</ul>
```

The first `<ul>` uses `inside`, while the second uses `outside`.

### Why It Matters

`list-style-position` is particularly useful when you care about **text alignment and wrapping** within list items.

A simple mental model is:

```text
outside:

•  List item content
   continues here


inside:

• List item content
  continues here
```

The exact visual result depends on the surrounding layout and the amount of text, but the important distinction is whether the marker is treated as being **outside or inside the content area**.

---

## 3. `list-style-image`

The `list-style-image` property allows you to use an **image instead of the normal list marker**.

This can be useful when you want a more customized visual style.

### Example

```html
<head>
  <style>
    ul {
      list-style-image: url('https://cdn.freecodecamp.org/platform/universal/freecodecamp-org-gravatar.jpeg');
      list-style-position: inside;
    }
  </style>
</head>

<body>
  <ul>
    <li>Item 1</li>
    <li>Item 2</li>
    <li>Item 3</li>
  </ul>
</body>
```

In this example, the list uses a custom FreeCodeCamp image as its marker.

### Practical Note

The image used as a list marker should be **small and appropriate for the design**.

> If the image is too large or visually complex, it can make the list harder to read.

---

## 4. The `list-style` Shorthand

Instead of setting the three properties separately, you can combine them using the `list-style` shorthand property.

The three individual properties are:

```text
list-style-type
list-style-position
list-style-image
```

### Example

```html
<ul style="list-style: square inside url('https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg');">
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```

This shorthand specifies:

- `square` → the list marker type
- `inside` → the marker position
- `url(...)` → the image used as the marker

Conceptually:

```text
list-style: type position image;
```

The values can be combined in the shorthand rather than writing each property separately.

### Fallback Behavior

If the image cannot be loaded or does not render, the `square` marker can be used as a fallback in this example.

This makes the shorthand useful when you want to specify several aspects of a list's appearance in one declaration.

---

## 5. Comparing the Three Properties

| Property              | Main Question It Answers                   | Example                  |
| --------------------- | ------------------------------------------ | ------------------------ |
| `list-style-type`     | **What should the marker look like?**      | `square`                 |
| `list-style-position` | **Where should the marker be positioned?** | `inside`                 |
| `list-style-image`    | **Should an image be used as the marker?** | `url(...)`               |
| `list-style`          | **Can I set these together?**              | `square inside url(...)` |

### Mental Model

Think of a list marker as having three customizable aspects:

```text
                 LIST MARKER
                      │
        ┌─────────────┼─────────────┐
        │             │             │
       TYPE        POSITION        IMAGE
        │             │             │
    What it is     Where it is    Image used
        │             │             │
     square        inside          url(...)
```

The `list-style` shorthand brings these settings together.

---

## Summary

The `list-style` property controls the appearance of list markers and is a shorthand for three properties:

1. **`list-style-type`** — controls the type of bullet or numbering.
2. **`list-style-position`** — controls whether the marker is positioned `inside` or `outside` the list item's content.
3. **`list-style-image`** — allows an image to be used as the list marker.
4. **`list-style`** — combines these settings into a single shorthand declaration.

### Key Takeaways

- Use `list-style-type` when you want to change **the bullet or numbering style**.
- Use `list-style-position` when you want to control **the marker's position relative to the content**.
- Use `list-style-image` when you want to use **a custom image as the marker**.
- Use `list-style` when you want to specify multiple list-style settings **in one declaration**.
- Keep custom marker images small and visually appropriate so they do not reduce readability.
