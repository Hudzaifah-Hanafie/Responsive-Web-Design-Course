# CSS Inheritance

CSS inheritance is a mechanism that allows certain styles applied to a parent element to be passed down to its child elements.

It is useful for applying consistent styling across related elements without having to repeat the same CSS for every child.

---

## 1. What Is Inheritance?

In CSS, **inheritance means that a child element can receive certain property values from its parent element**.

A useful mental model is:

> **Parent → Child**

When a property is inherited, the child starts with the value from its parent unless the child has its own value that overrides it.

This can make stylesheets more concise because a style can be defined once on a parent instead of being repeated on many child elements.

---

## 2. Not All CSS Properties Are Inherited

An important point is that **inheritance does not apply to every CSS property by default**.

Some commonly inherited properties include:

- `color`
- `font-family`
- `line-height`

For example, if a parent element has `color: blue`, its child elements can inherit that text color.

### Example

```html
<div style="color: blue;">
  This is the parent element.
  <p>This is the child element inheriting the color.</p>
</div>
```

Here, both the `div` and the `p` display their text in blue because `color` is inherited.

### Why This Matters

You can often style a group of related elements by setting a property on their common parent instead of repeating the same rule on every child.

---

## 3. Properties That Do Not Inherit by Default

Other CSS properties are **not inherited by default**.

Examples include:

- `margin`
- `padding`
- `border`
- `background`

For example, giving a parent element `padding: 20px` does not automatically give its child elements the same `20px` padding.

> **Important:** Inheritance is property-specific. Always check whether a property is inherited by default rather than assuming that every style is passed to children.

---

## 4. Forcing Inheritance with `inherit`

CSS provides the `inherit` keyword when you explicitly want a property to take its parent's value.

This is useful even for properties that do not normally inherit.

### Example

```html
<div style="padding: 20px;">
  This is the parent element with padding.
  <p style="padding: inherit;">This is the child element inheriting the padding.</p>
</div>
```

In this example:

1. The parent `div` has `padding: 20px`.
2. The `p` normally would not inherit `padding`.
3. `padding: inherit` explicitly tells the `p` to use its parent's padding value.
4. The child therefore receives `20px` of padding.

---

## 5. Inheritance Only Goes from Parent to Child

Inheritance works in **one direction**:

```text
Parent
  ↓
Child
  ↓
Grandchild
```

A child can receive an inherited value from its parent, but changing the child does not change the parent.

For example, if a child overrides an inherited property, that new value applies to the child rather than being passed upward to the parent.

> **Remember:** CSS inheritance flows downward through the element hierarchy, not upward.

---

## 6. Why CSS Inheritance Is Useful

Inheritance helps with two important goals:

### Consistency

A common style can be applied to a parent and shared by its descendants.

For example, setting a common text color on a parent can give all relevant child text the same color.

### Less Repetition

Instead of writing the same style for many elements, you can define it once on a parent when the property is inheritable.

This can make CSS:

- more concise,
- easier to read,
- easier to maintain.

---

## 7. Mental Model

Think of CSS inheritance as **values flowing down the element tree**:

```text
Parent
│
├── Child A
│    └── Grandchild
│
└── Child B
```

If an inheritable property is set on the parent:

```text
Parent: color: blue
        ↓
Child A: color: blue
        ↓
Grandchild: color: blue

Child B: color: blue
```

A child can override the inherited value:

```text
Parent: color: blue
        ↓
Child:  color: red
```

The parent's value remains `blue`; only the child's value changes.

---

## Summary

| Concept | Description |
|---|---|
| **Inheritance** | Allows certain CSS property values to pass from a parent to its children. |
| **Inherited properties** | Properties such as `color`, `font-family`, and `line-height` inherit by default. |
| **Non-inherited properties** | Properties such as `margin`, `padding`, `border`, and `background` do not inherit by default. |
| **`inherit`** | Explicitly tells an element to use the corresponding value from its parent. |
| **Direction** | Inheritance flows from parent to child, not from child to parent. |
| **Main benefit** | Reduces repeated styles and helps maintain consistent styling. |

---

## Key Takeaways

- **CSS inheritance passes certain property values from parent elements to child elements.**
- **Not every CSS property is inherited by default.**
- `color`, `font-family`, and `line-height` are examples of commonly inherited properties.
- `margin`, `padding`, `border`, and `background` do not inherit by default.
- Use `inherit` when you explicitly want a child to use its parent's value.
- **Inheritance flows downward from parent to child.**
- Overriding a value on a child does **not** change the parent.
- Inheritance can make CSS more concise, consistent, and easier to maintain.
