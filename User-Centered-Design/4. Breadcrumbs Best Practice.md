# Breadcrumbs: Design Best Practices

Breadcrumbs are a secondary navigation aid that shows users where the current page sits within a website's hierarchy. They are especially useful on websites with several levels of navigation, such as e-commerce stores, news sites, and technical documentation.

For example, a product page might show this path:

```text
Home / Electronics / Phones / Smartphone XYZ
```

This path communicates the hierarchy from the homepage to the current product. It can also help users move back to a broader category without having to start over.

---

## 1. How Breadcrumbs Work

A website can provide navigation through elements such as a top navigation bar, a sidebar, or a footer. On a site with a deeper hierarchy, breadcrumbs provide an additional way to understand the current location.

Consider this example:

```html
<link rel="stylesheet" href="styles.css">

<div class="breadcrumbs">
  Home / Electronics / Phones / Smartphone XYZ
</div>
```

```css
.breadcrumbs {
  font-size: 0.9rem;
  color: #555;
  margin: 1rem 0;
}
```

The breadcrumb path represents these levels:

1. `Home` — the homepage.
2. `Electronics` — a broad product category.
3. `Phones` — a more specific category.
4. `Smartphone XYZ` — the current product page.

The HTML example displays the path as text, while the CSS styles the element. This simplified example does not make the individual breadcrumb items clickable; it illustrates the visual presentation.

### Why Breadcrumbs Are Useful

Breadcrumbs help users:

- **Understand their location:** See how the current page fits into the site's hierarchy.
- **Navigate to broader sections:** Return to a parent category or another earlier level.
- **Recover context:** Understand a page even when they arrive directly from a search result or an external link.

---

## 2. Choose a Clear Separator

A **separator** is the character or symbol placed between breadcrumb levels. Common choices include:

- Greater-than sign: `>`
- Right angle quotation marks: `»`
- Forward slash: `/`

For example:

```html
<div class="breadcrumbs">
  Home &gt; Electronics &gt; Phones &gt; Smartphone XYZ
</div>
```

In HTML, `&gt;` represents the greater-than character (`>`). It allows the character to be displayed as text in the breadcrumb path.

### Practical Guidance

Choose a separator that makes the hierarchy easy to scan. The specific symbol is less important than using it consistently throughout the site.

---

## 3. Place Breadcrumbs Where Users Can Find Them

Breadcrumbs are typically placed near the top of the page, either above or below the main navigation bar.

They should be easy to locate without competing with the site's primary navigation. If users have to search for the breadcrumb trail, it becomes less useful.

### Example: Main Navigation and Breadcrumbs

```html
<nav class="main-nav">
  <a href="#">Home</a>
  <a href="#">Electronics</a>
  <a href="#">Phones</a>
</nav>

<div class="breadcrumbs">
  Home &gt; Electronics &gt; Phones &gt; Smartphone XYZ
</div>
```

```css
.main-nav {
  background-color: #333;
  padding: 1rem;
}

.main-nav a {
  color: white;
  margin-right: 1rem;
  text-decoration: none;
}

.breadcrumbs {
  font-size: 0.9rem;
  color: #555;
  margin: 1rem 0;
}
```

The example places the breadcrumb trail beneath the main navigation. The navigation links and breadcrumbs serve related but different purposes: the main navigation provides access to important site areas, while breadcrumbs communicate the current page's position in the hierarchy.

> **Important:** Breadcrumbs are a secondary navigation aid, not a replacement for the site's primary navigation.

---

## 4. Make Breadcrumbs Easy to Read Without Giving Them Too Much Emphasis

Breadcrumbs should be large enough to read comfortably, but they generally should not dominate the page. Their role is to provide context and navigation support, rather than to compete with the main content.

For example:

```html
<div class="breadcrumbs">
  Home &gt; Electronics &gt; Phones &gt; Smartphone XYZ
</div>

<p>
  Lorem ipsum dolor sit amet, consectetur adipiscing elit. Sed do eiusmod tempor incididunt ut labore et dolore magna aliqua.
</p>
```

```css
.breadcrumbs {
  font-size: 1rem;
  color: #555;
  margin: 1rem 0;
}

p {
  font-size: 1.2rem;
  line-height: 1.6;
}
```

In this example, the breadcrumb text is set to `1rem`, while the paragraph text is set to `1.2rem`. The difference illustrates how breadcrumbs can remain readable while allowing the main content to receive more visual emphasis.

### Practical Guidance

- Keep the breadcrumb text legible.
- Avoid making the trail so large that it takes unnecessary space.
- Treat breadcrumbs as supporting information rather than the page's main focus.

The exact size depends on the design; the goal is a useful balance between readability and visual hierarchy.

---

## 5. Decide Whether Breadcrumbs Are Necessary

Breadcrumbs are most useful when a website has a **deep hierarchy**—that is, several levels between the homepage and a particular page.

They may add little value on a simple site with only a few navigation levels. In that situation, the hierarchy may already be easy to understand without an additional navigation trail.

Breadcrumbs are commonly found on:

- **E-commerce websites**, where products are grouped into categories and subcategories.
- **News websites**, where articles may belong to sections and topics.
- **Technical documentation websites**, where pages are organized into nested sections.

### A Simple Decision Rule

- **Use breadcrumbs when:** Users may need help understanding their location within a multi-level site or returning to a broader category.
- **Consider omitting them when:** The site has a shallow hierarchy and the trail would provide little additional value.

---

## Summary

| Design consideration | Main goal | Practical guidance |
|---|---|---|
| Separator | Make levels easy to distinguish | Choose a clear symbol, such as `>`, `»`, or `/`, and use it consistently. |
| Placement | Help users find the trail | Place breadcrumbs near the top of the page, above or below the main navigation. |
| Size | Keep the trail readable without making it dominant | Use legible text while giving the main content greater visual emphasis. |
| When to use them | Provide context on complex sites | Favor breadcrumbs for deep hierarchies; they may be unnecessary on simple sites. |

## Key Takeaways

- Breadcrumbs show where a page sits within a website's hierarchy.
- They help users understand context and navigate back to broader sections.
- Choose a consistent separator, place breadcrumbs where they are easy to find, and keep them readable.
- Breadcrumbs support primary navigation; they do not replace it.
- They are most valuable on websites with multiple levels of navigation.
