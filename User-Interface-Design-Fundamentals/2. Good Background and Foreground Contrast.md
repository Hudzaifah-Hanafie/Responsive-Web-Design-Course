# Background and Foreground Contrast in Web Design

Contrast is one of the most important parts of making a design readable and accessible. In a web page, the relationship between a **foreground** color (such as text) and its **background** color determines how easily users can distinguish the two.

> **Note:** Some examples in the original material use CSS that may be unfamiliar at this stage. You do not need to understand every line of the CSS yet. The examples are mainly here to make the visual contrast concepts easier to understand.

---

## 1. Understanding Contrast

### What Is Contrast?

**Contrast** is the difference between two colors, or more practically, how easy it is to distinguish one color from another.

- **High contrast** → the colors are visually distinct.
- **Low contrast** → the colors are visually similar and harder to distinguish.

A simple example is:

- **Black + white** → very high contrast.
- **Light blue + light purple** → much lower contrast.

The same idea applies when colors are used for text and backgrounds.

### Example: High vs. Low Contrast

```html
<style>
  .example {
    padding: 20px;
    margin-bottom: 20px;
    font-size: 18px;
    font-family: sans-serif;
  }

  .high-contrast {
    background-color: black;
    color: white;
  }

  .low-contrast {
    background-color: #add8e6;
    color: #dda0dd;
  }

  .label {
    font-weight: bold;
    margin-bottom: 5px;
  }
</style>

<div class="example high-contrast">
  <div class="label">High Contrast</div>
  This text has high contrast (black background and white text).
</div>

<div class="example low-contrast">
  <div class="label">Low Contrast</div>
  This text has low contrast (light blue background and light purple text).
</div>
```

The important idea is not the particular CSS classes. The example demonstrates the visual difference between colors that are easy to distinguish and colors that are harder to distinguish.

## 2. Contrast Between Text and Backgrounds

Contrast becomes especially important when dealing with **text**.

A design can use the same general colors as the previous example, but the contrast now directly affects how easily users can read the content.

### High-Contrast Text

Black text on a white background is a familiar example of high contrast:

```html
<style>
  .text-example {
    padding: 10px;
    margin-bottom: 20px;
    font-size: 18px;
    font-family: sans-serif;
  }

  .text-high-contrast {
    background-color: white;
    color: black;
  }

  .text-low-contrast {
    background-color: #add8e6;
    color: #dda0dd;
  }

  .label {
    font-weight: bold;
    margin-bottom: 5px;
    display: block;
  }
</style>

<div class="text-example text-high-contrast">
  <span class="label">High Contrast Text</span>
  This is high contrast text: black text on a white background.
</div>

<div class="text-example text-low-contrast">
  <span class="label">Low Contrast Text</span>
  This is low contrast text: purple text on a light blue background.
</div>
```

The first example is easy to read because the text and background are visually very different. The second is harder to read because the colors are more similar.

> **Practical rule:** When choosing text and background colors, do not judge contrast only by whether the colors look attractive together. The text also needs to remain easy to read.

## 3. WCAG Contrast Standards

### Why a Standard Is Needed

You cannot rely only on your own eyesight to decide whether a color combination has "good enough" contrast. Different users can experience colors and readability differently.

The **Web Content Accessibility Guidelines (WCAG)** provide standards for evaluating contrast.

For normal text, the material uses these two important levels:

| WCAG Level | Contrast Ratio | Meaning |
|---|---:|---|
| **AA** | **4.5:1** | Minimum contrast level described here for accessible text |
| **AAA** | **7:1** | Higher level of accessibility |

So, as a general target from this material:

> **4.5:1 is the minimum AA target, while 7:1 is the stronger AAA target.**

### AA Example

```html
<style>
  .contrast-example {
    padding: 15px;
    margin-bottom: 20px;
    font-size: 18px;
    font-family: sans-serif;
  }

  .aa-contrast {
    background-color: #ffffff;
    color: #4b4b4b;
  }

  .aaa-contrast {
    background-color: #ffffff;
    color: #1a1a1a;
  }

  .label {
    font-weight: bold;
    margin-bottom: 8px;
    display: block;
  }
</style>

<div class="contrast-example aa-contrast">
  <span class="label">AA Standard (Contrast Ratio ~4.5:1)</span>
  This text meets the minimum accessibility standard for contrast.
</div>

<div class="contrast-example aaa-contrast">
  <span class="label">AAA Standard (Contrast Ratio ~7:1)</span>
  This text meets the highest accessibility standard for contrast.
</div>
```

The examples show that a measurable contrast ratio gives you a more reliable target than simply deciding whether two colors "look different enough."

## 4. Understanding Contrast Ratios

### What Is a Contrast Ratio?

A **contrast ratio** expresses the difference in relative brightness between two colors.

It is written as a ratio such as:

- `1:1` → essentially no contrast.
- `4.5:1` → the AA target described above.
- `7:1` → the AAA target described above.
- `21:1` → the highest contrast ratio demonstrated by black and white.

The larger the ratio, the greater the contrast between the two colors.

### How to Check Contrast

There are websites and tools that can calculate the contrast ratio between two colors. Many modern browsers also provide ways to inspect contrast directly through their **developer tools**.

This is useful because you do not have to estimate accessibility by looking at the colors yourself.

## 5. A 21:1 Contrast Example

Black text on a white background has a contrast ratio of **21:1**.

```html
<style>
  .contrast-21 {
    background-color: white;
    color: black;
    padding: 15px;
    font-family: sans-serif;
    font-size: 18px;
    margin-bottom: 20px;
  }

  .label {
    font-weight: bold;
    margin-bottom: 8px;
    display: block;
  }
</style>

<div class="contrast-21">
  <span class="label">Contrast Ratio 21:1</span>
  This is black text on a white background, which has the highest contrast ratio of 21:1.
</div>
```

This is far above the `7:1` AAA target.

### A Low-Contrast Example

Now compare that with purple text on a blue background:

```html
<style>
  .contrast-21 {
    background-color: white;
    color: black;
    padding: 15px;
    font-family: sans-serif;
    font-size: 18px;
    margin-bottom: 20px;
  }

  .label {
    font-weight: bold;
    margin-bottom: 8px;
    display: block;
  }

  .purple-on-blue {
    background-color: #0000cc;
    color: #800080;
    padding: 15px;
    font-family: sans-serif;
    font-size: 18px;
    margin-bottom: 20px;
  }
</style>

<div class="contrast-21">
  <span class="label">Contrast Ratio 21:1</span>
  This example more than meets the AAA standard with black text on white background.
</div>

<div class="purple-on-blue">
  <span class="label">Purple on Blue (Lower Contrast)</span>
  This doesn't meet the AA standard.
</div>
```

The purple-on-blue example has a contrast ratio of **1.48:1**, which does not meet the AA standard.

### Key Lesson

Two colors can look different to you and still have an insufficient contrast ratio.

That is why measurable contrast ratios are important when designing accessible interfaces.

---

## 6. Adjusting Color Properties to Improve Contrast

If a color combination does not have enough contrast, you can adjust the colors.

The material demonstrates three color properties that can be changed:

1. **Hue**
2. **Saturation**
3. **Lightness**

These changes alter the resulting colors and, therefore, can change the contrast between the foreground and background.

> **Important:** The goal is not simply to make the colors look more different. The final combination should reach an appropriate accessibility contrast ratio.

---

## 7. Adjusting Hue

### What Is Hue?

**Hue** describes the general type of color, such as:

- red
- blue
- orange
- green

The first attempt to improve the purple-on-blue example is to change the foreground hue.

Instead of purple, the example uses red:

```html
<style>
  .contrast-21 {
    background-color: white;
    color: black;
    padding: 15px;
    font-family: sans-serif;
    font-size: 18px;
    margin-bottom: 20px;
  }

  .label {
    font-weight: bold;
    margin-bottom: 8px;
    display: block;
  }

  .red-on-blue {
    background-color: #0000cc;
    color: #ff0000;
    padding: 15px;
    font-family: sans-serif;
    font-size: 18px;
    margin-bottom: 20px;
  }
</style>

<div class="contrast-21">
  <span class="label">Contrast Ratio 21:1</span>
  This example more than meets the AAA standard with black text on white background.
</div>

<div class="red-on-blue">
  <span class="label">Red on Blue (Higher Contrast Hue Shift)</span>
  This doesn't meet accessibility standards.
</div>
```

Changing the hue from purple to red changes the visual relationship between the foreground and background.

However, in this example the change is **not enough** to reach the accessibility target. The resulting contrast ratio is only **1.49:1**.

### Lesson

> **Changing hue can help, but changing the color family alone does not guarantee sufficient contrast.**

---

## 8. Adjusting Saturation

### What Is Saturation?

**Saturation** describes the amount or intensity of color present in a color.

The material next increases the saturation of the red foreground.

```html

  .high-sat-red-on-blue {
    background-color: #0000cc;
    color: #ff4d4d;
    padding: 15px;
    font-family: sans-serif;
    font-size: 18px;
    margin-bottom: 20px;
  }
</style>

<div class="contrast-21">
  <span class="label">Contrast Ratio 21:1</span>
  This example more than meets the AAA standard with black text on white background.
</div>

<div class="low-sat-red-on-blue">
  <span class="label">Low Saturation Red on Blue (Contrast ~1.49:1)</span>
  This red has low saturation, resulting in a poor contrast ratio.
```

- Lower-saturation red → approximately **1.49:1**

### Lesson

> **Improving saturation can increase contrast, but it may still not be enough to meet accessibility requirements.**

---

## 9. Adjusting Lightness

### What Is Lightness?

**Lightness** describes how light or dark a color is. In the material's explanation, it is described in terms of how much white is present in the color.

The next step is to make the red darker.

This produces a much stronger difference between the foreground and the light-blue background.

```html
<style>
  .contrast-21 {
    background-color: white;
    color: black;
    padding: 15px;
    font-family: sans-serif;
    font-size: 18px;
    margin-bottom: 20px;
  }

  .label {
    font-weight: bold;
    margin-bottom: 8px;
    display: block;
  }

  .blue-bg {
    background-color: #add8e6;
    padding: 15px;
    font-family: sans-serif;
    font-size: 18px;
    margin-bottom: 20px;
  }

  .low-sat-red-on-blue {
    background-color: #0000cc;
    color: #b23333;
    margin-bottom: 20px;
  }

  .high-sat-red-on-blue {
    background-color: #0000cc;
    color: #ff4d4d;
    margin-bottom: 20px;
  }

  .dark-red-on-light-blue {
    background-color: #add8e6;
    color: #8b0000;
  }
</style>

<div class="contrast-21">
  <span class="label">Contrast Ratio 21:1</span>
  This example more than meets the AAA standard with black text on white background.
</div>

<div class="low-sat-red-on-blue blue-bg">
  <span class="label">Low Saturation Red on Medium Blue (Contrast ~1.49:1)</span>
  This red has low saturation, resulting in a poor contrast ratio.
</div>

<div class="high-sat-red-on-blue blue-bg">
  <span class="label">Higher Saturation Red on Medium Blue (Contrast ~3.54:1)</span>
  Increasing the saturation of red improves contrast but it’s still below AA standard.
</div>

<div class="dark-red-on-light-blue">
  <span class="label">Darker Red on Light Blue (Contrast ~10.34:1)</span>
  Decreasing the lightness of the red increases the contrast ratio significantly.
</div>
```

The darker red on the light-blue background reaches a contrast ratio of approximately **10.34:1**, which is comfortably above the `7:1` AAA target described earlier.

### Lesson

Changing the lightness can have a much larger effect on contrast than changing the hue or saturation alone.

---

## 10. Putting the Adjustments Together

The examples demonstrate a progression:

| Adjustment | Example result | Meets AA (`4.5:1`)? |
|---|---:|---|
| Purple on blue | `1.48:1` | ❌ No |
| Red on blue | `1.49:1` | ❌ No |
| Higher-saturation red on blue | `3.54:1` | ❌ No |
| Dark red on light blue | `10.34:1` | ✅ Yes |
| Black on white | `21:1` | ✅ Yes |

The important point is that you can experiment with different color properties to find a combination that both looks appropriate and provides enough contrast.

However, visual preference should not take priority over accessibility.

> **Accessibility comes first.** If a visually attractive color combination makes text difficult to read or fails the required contrast ratio, the colors should be adjusted.

## Mental Model: Foreground vs. Background

A simple way to think about contrast is:

```text
        FOREGROUND
      (text / content)
             │
             │  must be easy to distinguish from
             ▼
        BACKGROUND
          (surface)
             │
             ▼
      Contrast Ratio
             │
       ┌─────┴─────┐
       ▼           ▼
    Too low     High enough
       │           │
       ▼           ▼
  Hard to read   More accessible
```

When choosing colors:

1. Choose a foreground and background color.
2. Check their contrast ratio.
3. If the ratio is too low, adjust the colors.
4. Recheck the ratio.
5. Prefer an accessible combination over one that is merely visually appealing.

---

## Practical Checklist

When creating text and background color combinations:

- [ ] Make sure the foreground and background are visually distinguishable.
- [ ] Do not rely only on your own perception of whether the colors look readable.
- [ ] Check the **contrast ratio** with an appropriate tool or browser developer tools.
- [ ] Aim for at least **4.5:1 (AA)** for the text discussed in this material.
- [ ] Aim for **7:1 (AAA)** when a higher level of accessibility is appropriate.
- [ ] Experiment with **hue**, **saturation**, and **lightness** when a color combination has insufficient contrast.
- [ ] Recheck the contrast ratio after changing a color.
- [ ] Remember that accessibility should take precedence over visual preference.

## Key Takeaways

1. **Contrast determines how easily foreground content can be distinguished from its background.**
2. **High contrast generally makes text easier to read, while low contrast can make it difficult to distinguish.**
3. **WCAG provides measurable contrast standards instead of relying only on personal judgment.**
4. For the text covered here, **`4.5:1` is the AA target** and **`7:1` is the AAA target**.
5. **Black text on white has a `21:1` contrast ratio**, providing very high contrast.
6. Changing **hue**, **saturation**, and **lightness** can change the resulting contrast.
7. A color change that looks better visually is not necessarily enough to meet an accessibility standard.
8. **Always prioritize accessibility when balancing visual design with readability.**
