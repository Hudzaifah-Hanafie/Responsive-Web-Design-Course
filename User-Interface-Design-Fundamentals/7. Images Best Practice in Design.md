# Best Practices for Working with Images in Web Design

Images can make a website more engaging, communicate ideas quickly, and support the content on a page. To use them effectively, consider both the technical side—such as responsiveness, resolution, and file size—and the visual side, including balance, hierarchy, alignment, and accessibility.

> **Learning note:** The examples below use HTML and CSS. You do not need to understand every CSS property immediately; focus first on the design principle each example demonstrates.

---

## 1. Make Images Responsive

A **responsive image** adapts to the available space so that it fits different screen sizes, such as desktop monitors, tablets, and mobile phones.

Without responsive sizing, an image may overflow its container or force users to scroll horizontally on a small screen.

A common starting point is:

```css
img {
  max-width: 100%;
  height: auto;
}
```

- `max-width: 100%` prevents an image from becoming wider than its containing element.
- `height: auto` preserves the image's original proportions as its width changes.

Together, these rules allow an image to shrink when space is limited without becoming distorted.

### Example: A Responsive Cat Image

```html
<style>
  body {
    font-family: sans-serif;
    padding: 20px;
    background-color: #fefefe;
    color: #333;
    text-align: center;
  }

  img {
    max-width: 100%;
    height: auto;
    border-radius: 8px;
  }

  p {
    font-size: 16px;
    max-width: 600px;
    margin: 20px auto;
    line-height: 1.6;
  }
</style>

<h1>Responsive Cat Image</h1>

<img
  src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/cats.jpg"
  alt="Two cats peacefully sleeping together."
/>

<p>
  This image scales with the available screen space. On a desktop or a mobile
  phone, it adjusts its width while keeping its proportions.
</p>
```

**What to notice:** The image uses `max-width: 100%` and `height: auto`. The `border-radius` property rounds the corners, but it is decorative rather than necessary for responsiveness.

### Why Responsiveness Matters

- Images remain usable on screens of different sizes.
- Content is less likely to overflow the layout.
- Users can view the page more comfortably on mobile devices.

## 2. Choose Suitable Image Resolution

A digital image is made up of **pixels**—small picture elements that combine to form the complete image.

**Pixels per inch (PPI)** describes how many pixels are represented in one inch when an image is displayed or printed at a particular size. Resolution and the number of pixels in an image affect how much detail it can show.

A suitable image should look clear at the size at which it will be displayed. If an image has too few pixels for the display size, it may look blurry or pixelated when enlarged.

### Practical Guidance

- Choose an image with enough detail for its intended display size.
- Check how it looks on the devices and screen sizes your site supports.
- Optimize the image for web use rather than uploading an unnecessarily large original.

> **Important:** Higher resolution is not automatically better for every situation. The goal is sufficient visual quality without making the file larger than necessary.

---

## 3. Use Appropriate Image Dimensions and File Sizes

Image dimensions and file size are related, but they are not the same:

- **Dimensions** describe the image's width and height, usually in pixels.
- **File size** describes how much storage or data the image requires, often measured in kilobytes (KB) or megabytes (MB).

An image that is much larger than the space where it appears may waste bandwidth and slow down page loading. Large files can be especially inconvenient for users with slow connections or limited data.

### Best Practices

1. Choose dimensions appropriate for the space where the image will appear.
2. Compress or otherwise optimize images for the web while maintaining acceptable visual quality.
3. Avoid using unnecessarily large files for small display areas.
4. Check the result to make sure optimization has not made the image visibly poor.

For example, a small thumbnail generally does not need the same image dimensions as a large, full-width feature image.

**The goal:** Images should be clear enough for their purpose and light enough to load efficiently.

## 4. Balance Images and Text

**Balance** is the distribution of visual weight across a design. A page can feel unbalanced when one image dominates the layout or when text and images are arranged without a clear relationship.

A balanced layout makes the content feel organized and helps users move naturally through the page.

### Example: A Balanced Layout

```html
<style>
  body {
    font-family: sans-serif;
    margin: 0;
    padding: 40px 20px;
    background-color: #f9f9f9;
    color: #333;
  }

  .container {
    display: flex;
    flex-wrap: wrap;
    align-items: center;
    justify-content: space-between;
    gap: 30px;
    max-width: 1000px;
    margin: 0 auto;
  }

  .text {
    flex: 1 1 400px;
  }

  .text h2 {
    font-size: 28px;
    margin-bottom: 10px;
  }

  .text p {
    font-size: 16px;
    line-height: 1.6;
  }

  .image {
    flex: 1 1 400px;
  }

  .image img {
    width: 100%;
    height: auto;
    border-radius: 8px;
  }
</style>

<div class="container">
  <div class="text">
    <h2>Balanced Layout</h2>
    <p>
      Balance is essential in web design. Pairing a block of text with a
      complementary image can create a layout that feels calm, structured,
      and easy to navigate.
    </p>
  </div>

  <div class="image">
    <img
      src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/cats.jpg"
      alt="Two cats peacefully sleeping together."
    >
  </div>
</div>
```

### What the Example Demonstrates

- The text and image occupy separate areas within one container.
- `display: flex` places the elements in a flexible layout.
- `gap: 30px` adds space between them.
- `flex-wrap: wrap` allows the items to move onto another line when there is not enough horizontal space.
- The image uses `width: 100%` and `height: auto` to fit its own layout area without distorting its proportions.

The exact layout depends on the available space, but the main idea is to make the text and image feel like complementary parts of the same section.

## 5. Establish Visual Hierarchy

**Visual hierarchy** is the order in which users are likely to notice and process elements on a page.

Not every image or section has equal importance. Images that support the main message or most important content should be placed and sized so that users can recognize their significance.

For example, a website for an animal shelter might feature a story about rescuing stray cats more prominently than a notice about a future fundraiser.

### Example: Using Placement to Show Importance

```html
<style>
  body {
    font-family: sans-serif;
    padding: 30px 20px;
    background-color: #fff;
    color: #222;
    max-width: 800px;
    margin: 0 auto;
  }

  .section {
    margin-bottom: 40px;
  }

  .section img {
    width: 100%;
    height: auto;
    border-radius: 8px;
    margin-bottom: 15px;
  }

  .section h2 {
    font-size: 24px;
    margin-bottom: 10px;
  }

  .section p {
    font-size: 16px;
    line-height: 1.6;
  }
</style>

<div class="section">
  <img
    src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/cats.jpg"
    alt="Two cats peacefully sleeping together."
  >
  <h2>Our Feline Rescue Mission</h2>
  <p>
    This image supports one of our most important stories—the rescue of
    12 stray cats from a storm drain. Placing it at the top helps visitors
    connect with the mission right away.
  </p>
</div>

<div class="section">
  <h2>Upcoming Fundraiser</h2>
  <p>
    Join us for a small fundraising event to support our shelter. It will be
    a casual afternoon with snacks, games, and plenty of cats.
  </p>
  <img
    src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/cats.jpg"
    alt="Two cats peacefully sleeping together."
  >
</div>
```

### What to Notice

The first section presents the image before the heading and paragraph, making the rescue mission visually prominent. In the second section, the heading and text appear before the image.

This is an example of how the order and placement of elements can influence what users notice first. Placement should reflect the importance and purpose of the content rather than being arbitrary.

## 6. Align Images with Other Elements

**Alignment** describes how elements are positioned in relation to one another. Consistent alignment helps a page feel connected and organized.

An image that is awkwardly positioned relative to its heading or paragraph can make a layout feel disjointed. Aligning related elements helps users understand that they belong together.

### Example: An Image Beside Text

```html
<style>
  body {
    font-family: sans-serif;
    padding: 40px 20px;
    background-color: #ffffff;
    color: #222;
    max-width: 900px;
    margin: 0 auto;
  }

  .aligned-content {
    display: flex;
    flex-wrap: wrap;
    align-items: center;
    gap: 20px;
  }

  .aligned-content img {
    width: 300px;
    height: auto;
    border-radius: 8px;
    flex-shrink: 0;
  }

  .aligned-text {
    flex: 1;
    min-width: 250px;
  }

  .aligned-text h2 {
    font-size: 24px;
    margin-bottom: 10px;
  }

  .aligned-text p {
    font-size: 16px;
    line-height: 1.6;
  }
</style>

<div class="aligned-content">
  <img
    src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/cats.jpg"
    alt="Two cats peacefully sleeping together."
  >

  <div class="aligned-text">
    <h2>Aligned Elements</h2>
    <p>
      The image sits horizontally beside the text block. Aligning these
      elements creates a cohesive layout, improves readability, and
      reinforces the structure of the page.
    </p>
  </div>
</div>
```

### What the Example Demonstrates

- `display: flex` arranges the image and text in a flexible layout.
- `align-items: center` aligns the items along the cross-axis, centering them vertically when they sit side by side.
- `gap: 20px` creates space between the image and text.
- `flex-wrap: wrap` allows the items to wrap when the available width is too small.
- `flex-shrink: 0` prevents the image from shrinking below its specified width through flex shrinking.
- `min-width: 250px` gives the text area a minimum width before wrapping behavior comes into play.

The purpose is not to memorize every property immediately. Notice how spacing, alignment, and flexible wrapping work together to make the layout easier to follow.

## 7. Make Images Accessible with Alternative Text

**Accessibility** means designing websites so that people with different abilities can use them. Images need particular consideration because users who cannot see an image may rely on a screen reader to understand the page.

The HTML `alt` attribute provides **alternative text**—a textual description that can be read by assistive technology when appropriate.

Example:

```html
<img
  src="cats.jpg"
  alt="Two cats peacefully sleeping together."
>
```

The `alt` text describes the meaningful content of the image rather than its appearance in code.

### Good Alternative Text

Useful alternative text should:

- Describe the image's relevant content or purpose.
- Be concise and specific.
- Convey information that matters in the surrounding context.

For example, `alt="Two cats peacefully sleeping together."` gives a reader a useful idea of what the photograph contains.

### Why It Matters

Without suitable alternative text, a user who cannot see the image may miss information that sighted users receive from it.

> **Practical note:** Alternative text should fit the image's purpose in context. The same image may need a different description—or no descriptive text if it is purely decorative—depending on how it is used.

---

## 8. A Practical Checklist for Using Images

Before publishing a page, review these questions:

- [ ] **Responsive sizing:** Can the image fit smaller screens without overflowing or becoming distorted?
- [ ] **Visual quality:** Is the image clear enough at the size where it appears?
- [ ] **Dimensions and file size:** Is the image appropriately sized and optimized for web delivery?
- [ ] **Balance:** Does the image work well with the text and surrounding elements?
- [ ] **Hierarchy:** Does its placement reflect the importance of the content?
- [ ] **Alignment:** Does it line up naturally with related headings, text, and other elements?
- [ ] **Accessibility:** Does the image have suitable alternative text when needed?

## Summary

| Principle | Meaning | Practical approach |
|---|---|---|
| Responsiveness | Images adapt to available space | Use `max-width: 100%` and `height: auto` as a common starting point |
| Resolution | The image contains enough detail for its display size | Choose a clear image suited to the intended size |
| Dimensions and file size | The image fits the layout without unnecessary download cost | Use appropriate dimensions and optimize the file |
| Balance | Visual weight is distributed effectively | Make images and text complement each other |
| Hierarchy | The design guides attention toward important content | Give prominent content suitable placement and emphasis |
| Alignment | Related elements have a coherent spatial relationship | Align images with associated text and other elements |
| Accessibility | Users with different abilities can understand the content | Provide meaningful `alt` text when appropriate |

## Key Takeaways

1. Images should support the content, not simply decorate the page.
2. Responsive sizing helps images work across screen sizes while preserving their proportions.
3. Choose an image that is clear enough for its intended use, but avoid unnecessarily large files.
4. Balance, hierarchy, and alignment help create a coherent visual layout.
5. The `alt` attribute can make meaningful image content available to people using screen readers.
6. Good image design considers both **how the page looks** and **how well it works for its users**.
