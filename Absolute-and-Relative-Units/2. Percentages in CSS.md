# Percentages in CSS

Percentages (`%`) are **relative CSS units**. They let you size or position an element in relation to another reference, rather than giving it a fixed value.

For example, `width: 50%` means that an element's width is half of the width of its containing block (usually its parent element).

Percentages are especially useful for **fluid and responsive layouts**, because an element can grow or shrink as its available space changes.

---

## 1. How Percentages Work

A percentage always needs a reference point. The reference depends on the CSS property being used.

For common layout properties:

- `width: 50%` means half of the containing block's width.
- `height: 50%` generally means half of the containing block's height, when that height is definite.
- `font-size: 120%` means 120% of the parent element's font size.

The important idea is that a percentage is not a fixed measurement. Its computed size depends on the relevant reference size.

### Example: Set an Element's Width and Height

**HTML**

```html
<link rel="stylesheet" href="styles.css" />

<div class="container">
  <div class="box"></div>
</div>
```

**CSS**

```css
.container {
  width: 400px;
  height: 200px;
  background-color: lightgray;
}

.box {
  width: 50%;
  height: 100%;
  background-color: red;
}
```

The `.container` is `400px` wide and `200px` tall. The `.box` uses percentages for both dimensions:

- `width: 50%` makes it `200px` wide (half of `400px`).
- `height: 100%` makes it `200px` tall (the full height of the container).

The red box therefore fills the container's height while taking up half its width.

> **Important:** Percentage heights can be tricky. A percentage height generally needs the containing block to have a definite height. If the parent’s height is not defined, the percentage height may not behave as expected.

---

## 2. Percentages for Flexible Layouts

Percentages are useful when an element should occupy a proportion of the available space instead of staying at one fixed width.

For example, `width: 80%` tells an element to use 80% of its containing block's width. If that containing block becomes wider or narrower, the element's width changes proportionally.

### Example: A Child That Uses 80% of Its Parent

**HTML**

```html
<link rel="stylesheet" href="styles.css" />

<div class="parent">
  <div class="child"></div>
</div>
```

**CSS**

```css
.parent {
  width: 100%;
  height: 300px;
  background-color: lightblue;
}

.child {
  width: 80%;
  height: 100%;
  background-color: red;
}
```

Here:

- `.parent` uses `width: 100%`, so it takes up the full width available to it.
- `.child` uses `width: 80%`, so it takes up 80% of the parent's width.
- `.child` uses `height: 100%`, so it fills the parent's `300px` height.

This kind of proportional sizing is useful for layouts that need to adapt to different container or screen widths.

### Why Use Percentages?

A fixed width such as `width: 400px` stays at `400px`, even when the available space changes. A percentage width changes with its reference container.

Use percentages when you want an element's dimensions to remain proportional to the space available to it.

---

## 3. Percentages for Responsive Images

Images can be wider than the space available on smaller screens. The CSS property `max-width: 100%` helps prevent an image from overflowing its containing block.

### Example: Make an Image Fit Its Container

**HTML**

```html
<link rel="stylesheet" href="styles.css" />

<img src="https://placehold.co/150x150" alt="Example Product Image" />
```

**CSS**

```css
img {
  max-width: 100%;
  height: auto;
}
```

What these declarations do:

- `max-width: 100%` prevents the image from becoming wider than its containing block.
- `height: auto` lets the browser calculate the height automatically, preserving the image's aspect ratio.

The image can scale down when the available width is smaller, rather than extending beyond its container.

> `max-width: 100%` sets a maximum width; it does not force every image to fill the entire container.

---

## 4. Percentages for Font Sizes

Percentages can also be used with `font-size` to make text size relative to its parent element.

For example, `font-size: 120%` makes the text 20% larger than the parent's font size.

### Example: Increase a Child Element's Font Size

**HTML**

```html
<link rel="stylesheet" href="styles.css" />

<div class="text-container">
  Parent text.
  <p class="text">This is some example text.</p>
</div>
```

**CSS**

```css
.text-container {
  font-size: 16px;
}

.text {
  font-size: 120%;
}
```

The parent text is `16px`. The paragraph's font size is 120% of that value:

- `100%` would be the same as the parent's `16px`.
- `120%` is 20% larger, which gives the paragraph a font size of `19.2px`.

This can be useful when you want text to scale in relation to surrounding text instead of assigning it an unrelated fixed size.

---

## 5. Percentages for Positioning and Centering

Percentages can be used with positioning properties such as `top`, as well as with `transform`, to place an element in relation to a container.

One common technique is to combine:

- `top: 50%` to move an absolutely positioned element's top edge to the halfway point of its containing block.
- `transform: translateY(-50%)` to move the element upward by half of its own height.

Together, these declarations vertically center the element.

### Example: Vertically Center an Element

**HTML**

```html
<link rel="stylesheet" href="styles.css" />

<div class="centered"></div>
```

**CSS**

```css
.centered {
  position: absolute;
  top: 50%;
  transform: translateY(-50%);
  width: 300px;
  height: 300px;
  background-color: red;
}
```

How it works:

1. `position: absolute` allows the element to be positioned using offsets such as `top`.
2. `top: 50%` places the element's top edge halfway down its containing block.
3. `transform: translateY(-50%)` moves the element upward by half of its own height.

Without the transform, the element's top edge would be at the halfway point, so the element itself would sit too low to be centered. The transform corrects this by shifting it upward by half its height.

This example introduces `position` and `transform`; these properties are covered in more detail in later lessons.

## 6. Important Things to Remember

### Percentages Depend on a Reference

A percentage is always relative to something, but the reference is determined by the property.

| CSS property | What the percentage is based on |
|---|---|
| `width` | The containing block's width |
| `height` | The containing block's height, when it is definite |
| `font-size` | The parent element's font size |
| `top` | The containing block's height |
| `translateY()` | The element's own transform reference box |

This table covers the properties used in the examples above. Percentage behavior can differ between CSS properties, so do not assume that every percentage is calculated from the parent's width or height.

### Be Careful with Nested Elements

When elements are nested, a percentage-based dimension is calculated in relation to the relevant containing block—not automatically in relation to the page or screen.

For example, if a child has `width: 50%`, it takes half of its containing block's width. If that containing block is itself only half as wide as the page, the child will be half of that smaller width.

### Percentage Heights Need Special Attention

Percentage-based heights can produce unexpected results when the parent does not have a definite height.

If `height: 100%` does not appear to fill the parent as expected, check whether the parent has an explicitly established height.

## Summary

| Use case | Example | Purpose |
|---|---|---|
| Proportional width | `width: 50%` | Make an element half as wide as its containing block |
| Fill available height | `height: 100%` | Make an element use the containing block's full height, when that height is definite |
| Flexible layout | `width: 80%` | Let an element's width adjust proportionally to its container |
| Responsive images | `max-width: 100%` | Prevent an image from exceeding its container's width |
| Relative typography | `font-size: 120%` | Make text 20% larger than its parent's font size |
| Vertical positioning | `top: 50%` | Place an element's top edge halfway down its containing block |
| Vertical centering | `translateY(-50%)` | Shift an element upward by half of its own height |

## Key Takeaways

- **Percentages are relative units.** Their values depend on a reference size determined by the CSS property.
- **Use percentages for proportional sizing.** They are useful when elements should adapt to the space available in their containers.
- **Use `max-width: 100%` for flexible images.** Pairing it with `height: auto` allows an image to scale down while keeping its aspect ratio.
- **Percentages can scale text.** For example, `font-size: 120%` is 20% larger than the parent's font size.
- **Percentage heights need a definite reference height.** Check the parent when a percentage height does not behave as expected.
- **Different properties can use different reference points.** For example, `top: 50%` and `translateY(-50%)` are not calculated from the same element.

## Mental Model

Think of a percentage as asking:

> **“How much of the relevant reference size should this value use?”**

For example:

```text
Containing block width: 400px
        |
        +-- Child width: 50%
                |
                +-- Result: 200px
```

The percentage is a proportion, not a fixed measurement. If the reference size changes, the resulting value can change too.
