# CSS `calc()` Function

The CSS `calc()` function lets you perform calculations directly inside a CSS property value.

It is useful when a value needs to depend on more than one measurement—for example, when an element should occupy a percentage of its parent container, but also needs a fixed amount of space added or removed.

```css
.element {
  width: calc(50% - 20px);
}
```

In this example, the element's width is calculated as half of its containing block's width minus `20px`. Because the percentage can change as the container changes size, the resulting width is flexible.

---

## 1. Understanding CSS Functions

A **function** is a reusable piece of code that performs a specific task. CSS includes built-in functions that you can use in property values.

To use a function, you **call** it by writing:

1. The function's name.
2. An opening parenthesis `(`.
3. The arguments the function needs.
4. A closing parenthesis `)`.

For example:

```css
function(argument1, argument2, argument3)
```

The values passed into a function are called **arguments**. A function can accept one argument or several, depending on what it needs.

### The `calc()` Function's Argument

`calc()` takes one argument: an **expression**.

An expression is a combination of values and operators that produces a result.

```css
calc(expression)
```

For example:

```css
calc(100% - 20px)
```

Here:

- `100%` and `20px` are the values, also called **operands**.
- `-` is the operator.
- The complete expression is the argument passed to `calc()`.

The browser **evaluates** the expression: it performs the calculation and uses the resulting value for the CSS property.

---

## 2. Values and Operators Supported by `calc()`

You can use `calc()` to calculate values involving:

- Lengths, such as `px`, `em`, and other CSS length units
- Percentages (`%`)
- Angles
- Time values
- Numbers

You can also combine compatible values with different units. For example, a length expressed as a percentage can be combined with a fixed length in pixels.

### Arithmetic Operators

`calc()` supports four arithmetic operators:

| Operator | Operation | Example |
|---|---|---|
| `+` | Addition | `calc(100px + 20px)` |
| `-` | Subtraction | `calc(100% - 20px)` |
| `*` | Multiplication | `calc(5 * 10px)` |
| `/` | Division | `calc(100% / 2)` |

For addition and subtraction, the operands must have units that can be combined for the calculation. Those units do not have to be identical: for example, a percentage can be subtracted from a pixel length.

### Order of Operations

When an expression contains multiple operators, `calc()` follows the standard mathematical order of operations.

Use parentheses when you want to make the intended order explicit or override the default order.

```css
.element {
  width: calc((100% - 40px) / 2);
}
```

The expression inside the inner parentheses is calculated first. The result is then divided by `2`.

---

## 3. Example: Calculating a Responsive Width

Consider this HTML:

```html
<link rel="stylesheet" href="styles.css" />

<div>Hello, World!</div>
```

You can style the `div` with white text, a dark blue background, and a calculated width:

```css
div {
  color: white;
  background-color: #1b1b32;
  width: calc(50% - 20px);
}
```

### How the Width Is Calculated

The important declaration is:

```css
width: calc(50% - 20px);
```

It contains two operands with different units:

- `50%` is relative to the width of the containing block.
- `20px` is a fixed length.
- `-` subtracts the fixed length from the percentage-based value.

The browser calculates the width by taking half of the containing block's width and subtracting `20px`.

For example, if the containing block is `800px` wide:

```text
50% of 800px = 400px
400px - 20px = 380px
```

The `div` therefore has a calculated width of `380px` in this example.

If the containing block becomes wider or narrower, the percentage changes and the browser recalculates the result.

### Why This Is Useful

Without `calc()`, you might have difficulty expressing a value that combines a relative measurement with a fixed adjustment.

`calc()` makes it possible to combine them in one property value. This is useful when building flexible layouts that need to respond to changes in their container or viewport.

> **Key idea:** Percentages provide relative sizing, while fixed units such as `px` provide a specific adjustment. `calc()` lets you combine both.

### Using Functions and Variables in an Expression

A `calc()` expression can also contain other CSS functions and CSS variables.

This allows calculations to use values produced by another function or stored in a variable. CSS variables are covered in more detail in later lessons.

## 4. Best Practices and Important Rules

### 4.1 Put Spaces Around Addition and Subtraction

The `+` and `-` operators must have whitespace around them.

**Invalid:**

```css
width: calc(100% -30px);
```

There is no space between the subtraction operator and the second operand.

**Valid:**

```css
width: calc(100% - 30px);
```

The spaces make the expression valid and easier to read.

Whitespace is not required around multiplication (`*`) and division (`/`), but using it is recommended for readability.

### 4.2 Include Units for Zero Length Values

When zero represents a length in a `calc()` expression, include a unit.

**Invalid:**

```css
width: calc(100% - 0);
```

**Valid:**

```css
width: calc(100% - 0px);
```

Although CSS commonly allows unitless `0` in many other contexts, the lesson's `calc()` length example requires a length unit for this operand.

### 4.3 Multiplication: One Operand Must Be Unitless

For multiplication, one operand must be a number without a unit.

**Invalid:**

```css
width: calc(5px * 50px);
```

Both operands have length units, so this multiplication is not valid.

**Valid alternatives:**

```css
width: calc(5 * 50px);
width: calc(5px * 50);
```

In each valid example, one operand is unitless. The result retains the length unit.

### 4.4 Division: Understand What Happens to the Units

Division can be used in two useful ways.

**Divide by a unitless number**

When a value is divided by a unitless number, the value is scaled and keeps its unit.

```css
width: calc(50% / 5);
```

This divides the percentage by `5`, so the result is `10%`.

**Divide values with matching units**

Dividing two values with matching units cancels out the units and produces a unitless number.

```css
calc(50% / 5%)
```

The result is the unitless number `10`.

Unitless results are suitable only for CSS properties that accept numbers, such as `line-height` or `flex-grow`. They are not interchangeable with length values.

### 4.5 Nesting `calc()` Calls

You can nest `calc()` calls when one calculation needs to be used as part of another calculation.

This can be useful when a larger value is easier to understand as several smaller calculations.

## 5. Quick Reference

| Topic | Rule |
|---|---|
| Function call | Write the function name followed by parentheses: `calc(...)`. |
| Argument | `calc()` takes an expression as its argument. |
| Supported operators | Addition (`+`), subtraction (`-`), multiplication (`*`), and division (`/`). |
| Different units | Compatible units, such as `%` and `px`, can be combined in calculations. |
| Operator spacing | Put whitespace around `+` and `-`. |
| Multiplication | One operand must be unitless. |
| Division by a number | The result keeps the original unit. |
| Division by a matching unit | The units cancel, producing a unitless number. |
| Parentheses | Use them to control or clarify the order of operations. |
| Nesting | `calc()` calls can be nested. |

---

## 6. Key Takeaways

- `calc()` performs calculations inside CSS property values.
- Its argument is an expression made up of values and operators.
- It can combine compatible values with different units, such as percentages and pixels.
- It is especially useful for flexible layouts that combine relative sizing with fixed adjustments.
- Always put spaces around addition and subtraction operators.
- For multiplication, one operand must be unitless.
- Division by a unitless number preserves the unit; division by a value with a matching unit produces a unitless number.

## 7. Mental Model

Think of `calc()` as a small calculator embedded in a CSS declaration:

```text
CSS property
    |
    v
calc(expression)
    |
    v
Browser evaluates the expression
    |
    v
Calculated value is used by the property
```

For a responsive width such as `calc(50% - 20px)`:

```text
Containing block width
        |
        v
Calculate 50% of that width
        |
        v
Subtract 20px
        |
        v
Use the result as the element's width
```

The percentage-based part can change when the containing block changes size, so the final result is recalculated automatically.
