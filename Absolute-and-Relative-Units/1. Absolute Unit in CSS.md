# Absolute Units in CSS

CSS length units define the size of things such as an element's width and height, the space around it, and the thickness of its borders.

CSS length units fall into two broad categories:

- **Absolute units** have fixed CSS reference lengths.
- **Relative units** are calculated in relation to something else, such as a font size, the viewport, or a parent element.

This note focuses on **absolute length units**.

---

## 1. What Are Absolute Units?

An absolute length unit represents a fixed length in CSS. Its value does not change in response to the size of the parent element or the screen.

For example, a width of `100px` remains `100px` whether the page is displayed on a small phone or a large desktop monitor.

This is different from a relative unit, whose computed size depends on another value or context.

> **Key idea:** Absolute units give you a fixed CSS measurement. Relative units adapt their size based on a reference.

## 2. The Pixel (`px`)

The **pixel (`px`)** is the absolute unit you will use most often in everyday CSS.

In CSS:

- `1px` is defined as `1/96` of an inch.
- A value such as `100px` specifies a fixed CSS length of 100 pixels.

### Example: Setting an Element's Dimensions

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<div class="box"></div>
```

CSS:

```css
.box {
  width: 100px;
  height: 100px;
  background-color: red;
}
```

The `.box` element is a red square with a width of `100px` and a height of `100px`.

Those CSS dimensions remain `100px` when the viewport changes size. The box does not automatically become wider on a large monitor or narrower on a small phone.

### CSS Pixels vs. Physical Screen Pixels

Although CSS defines `1px` as `1/96` of an inch, this does **not** mean that one CSS pixel always corresponds to one physical pixel on a display.

The actual physical size of a CSS pixel can vary depending on the device and display. Browsers and operating systems account for display characteristics when rendering CSS pixels.

> **Important:** Think of `px` as a fixed CSS measurement, not necessarily as one tiny physical dot on your screen.

## 3. Using Pixels for Spacing

Pixels are also commonly used to control spacing around elements.

For example, the `margin` property creates space **outside** an element's border.

### Example: Adding Margin to Two Boxes

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<div class="box"></div>
<div class="box"></div>
```

CSS:

```css
.box {
  width: 100px;
  height: 100px;
  background-color: red;
  margin: 10px;
}
```

Each box has:

- A width of `100px`.
- A height of `100px`.
- A margin of `10px` on every side.

Because `margin` is outside the box, it creates space around each element rather than inside it.

Pixels can also be used for other dimensions and spacing values, including:

- `width` and `height`
- `padding` (space inside an element's border)
- `margin` (space outside an element's border)
- `border-width` (the thickness of a border)

### When Should You Use Pixels?

Use `px` when you need a specific, fixed CSS measurement, such as:

- A precise border thickness.
- A particular amount of spacing.
- A fixed width or height for an element.

However, fixed dimensions are not always suitable for responsive layouts. A fixed width may not adapt well to a narrow screen. In those situations, relative units or flexible layout techniques may be more appropriate.

## 4. Other Absolute Length Units

CSS includes several other absolute length units. They are based on physical measurement units such as inches, centimeters, and points.

| Unit | Meaning | CSS conversion |
|---|---|---|
| `px` | Pixels | `1px` = `1/96` inch |
| `in` | Inches | `1in` = `96px` |
| `cm` | Centimeters | `1cm` = `96/2.54px` |
| `mm` | Millimeters | `1mm` = `1/10cm` |
| `Q` | Quarter-millimeters | `1Q` = `1/40cm` |
| `pt` | Points | `1pt` = `1/72` inch |
| `pc` | Picas | `1pc` = `1/6` inch |

Most of these units are more commonly encountered in print-related layouts than in everyday screen design. For typical web layouts, `px` is the absolute unit you are most likely to use.

## 5. Summary

| Concept | What to remember |
|---|---|
| Absolute units | Fixed CSS reference lengths; they are not relative to a parent element or viewport. |
| Relative units | Lengths calculated in relation to another value or context. |
| `px` | The most commonly used absolute CSS unit. `1px` equals `1/96` of an inch in CSS. |
| Physical pixel size | A CSS pixel does not necessarily match one physical display pixel. |
| `margin` | Creates space outside an element. |
| Other absolute units | Include `in`, `cm`, `mm`, `Q`, `pt`, and `pc`. |

## Key Takeaways

- CSS uses **absolute** and **relative** length units.
- Absolute units represent fixed CSS lengths.
- `px` is the most common absolute unit in everyday web development.
- A `100px` width stays `100px` as the viewport changes size.
- A CSS pixel is a reference measurement; its physical size can differ between displays.
- Absolute units are useful when a specific measurement is needed, but fixed dimensions should be chosen carefully when designing responsive layouts.
