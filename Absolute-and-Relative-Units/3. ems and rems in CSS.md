# CSS `em` and `rem` Units

CSS provides both absolute and relative length units. Pixels (`px`) are an absolute unit, while `em` and `rem` are relative units.

Relative units are useful when dimensions should respond to text size rather than remain fixed. This is especially helpful when building reusable components and creating more accessible typography.

This note explains how `em` and `rem` work, how they differ, and when to use each.

---

## 1. Understanding `em`

An `em` is a relative unit based on an element's font size.

The exact reference depends on which CSS property uses the unit:

- For the `font-size` property, `em` is calculated from the **parent element's font size**.
- For other properties, such as `margin`, `padding`, and `width`, `em` is calculated from the **font size of the element itself**.

This means that an element's spacing can scale along with its text.

### Example: Using `em` for a margin

**HTML**

```html
<link rel="stylesheet" href="styles.css" />

<p class="para">I am a paragraph element</p>

<div class="blue-box"></div>
```

**CSS**

```css
.para {
  font-size: 20px;
  margin-bottom: 1.5em;
  border: 2px solid red;
}

.blue-box {
  background-color: blue;
  color: white;
  padding: 10px;
  width: 100px;
  height: 100px;
}
```

The HTML contains two elements:

- A paragraph with the class `para`.
- A `div` with the class `blue-box`.

The `.para` rule sets the paragraph's font size to `20px` and its bottom margin to `1.5em`.

Because `margin-bottom` uses the paragraph's own font size as its reference:

\[
1.5 	imes 20	ext{px} = 30	ext{px}
\]

The paragraph therefore has a bottom margin of `30px`. The red border makes the paragraph's boundary easier to see, while the margin creates space between the paragraph and the blue box.

The `.blue-box` rule gives the `div` a blue background, white text, `10px` of padding on every side, and fixed dimensions of `100px` by `100px`.

### What if the paragraph has no explicit font size?

If you remove `font-size: 20px` from `.para`, the paragraph inherits its font size from its parent. In this example, the parent is the `body` element.

With the browser's default root and body text size of `16px`, the `1.5em` bottom margin is:

\[
1.5 	imes 16	ext{px} = 24	ext{px}
\]

The margin changes because the font size used as the reference has changed.

> **Important:** `em` values are not always based on the same element. For `font-size`, they refer to the parent's font size. For most other length properties, they refer to the element's own computed font size.

### When should you use `em`?

`em` is useful when the dimensions of a component should scale with that component's text.

For example, consider a reusable button. If its padding and margins use `em`, increasing the button's font size also increases its spacing. The button can grow proportionally instead of keeping the same fixed spacing around larger text.

Common use cases include:

- Button padding and spacing.
- Card spacing.
- Margins and other dimensions within components.
- Any component where proportions should follow its text size.

---

## 2. Understanding `rem`

A `rem` is a relative unit based on the font size of the root element: the HTML `html` element.

The difference is that `rem` always uses the root element as its reference, rather than the current element or its parent.

By default, browsers commonly use a root font size of `16px`.

For example:

\[
1	ext{rem} = 16	ext{px}
\]

This default can change if the root font size changes.

### Example: Using `rem` for typography

**HTML**

```html
<link rel="stylesheet" href="styles.css" />

<p>This is regular text.</p>
<p class="para">This text is slightly larger.</p>
```

**CSS**

```css
.para {
  font-size: 1.2rem;
  margin-bottom: 1.5em;
  border: 2px solid red;
}
```

The `.para` rule sets the paragraph's font size to `1.2rem`.

If the root font size is the default `16px`, the calculation is:

\[
1.2 	imes 16	ext{px} = 19.2	ext{px}
\]

The paragraph's font size is therefore `19.2px`.

Notice that `margin-bottom` still uses `em`, not `rem`. Since it is a margin property, its `1.5em` value is based on the paragraph's own computed font size.

### Why use `rem` for typography?

Users can change their browser's default font size. For example, someone with a visual impairment may increase it to make text easier to read.

When typography is defined using fixed pixel values, those values do not scale in proportion to changes in the root font size. Using `rem` allows text sizes to respond to changes in the root font size.

This makes `rem` a useful choice for accessible typography.

### When should you use `rem`?

Use `rem` when you want values to share a consistent reference point across the page.

Common use cases include:

- Font sizes.
- Page-wide spacing values.
- Layout dimensions that should scale consistently with the root font size.

`rem` can help keep spacing and layout values consistent across different elements because they all refer to the same root font size.

---

## 3. `em` vs. `rem`

Both units are relative to font size, but they use different reference points.

| Unit | Reference point | Useful for |
|---|---|---|
| `em` | The element's own font size for most length properties; the parent's font size for `font-size` | Component dimensions that should scale with the component's text |
| `rem` | The root (`html`) element's font size | Typography and consistent page-wide sizing |

### A simple way to remember the difference

- **`em` follows the local text size.** It is useful when a component's spacing should grow or shrink with that component's font.
- **`rem` follows the root text size.** It is useful when values across the page should share one consistent sizing reference.

---

## 4. Practical Guidelines

When choosing between pixels, `em`, and `rem`, think about what should control the size.

| If you want... | Consider using... |
|---|---|
| A fixed size that does not depend on font size | `px` |
| A component's spacing to scale with its text | `em` |
| Typography to scale with the root font size | `rem` |
| Consistent spacing values across different elements | `rem` |

These are practical guidelines rather than strict rules. The appropriate unit depends on the behavior you want from the design.

---

## Summary

| Concept | What to remember |
|---|---|
| `em` | A relative unit whose reference depends on the property. For `font-size`, it uses the parent font size; for most other length properties, it uses the element's own font size. |
| `rem` | A relative unit based on the root (`html`) element's font size. |
| Default root size | Commonly `16px` in browsers, unless changed. |
| `1.5em` at `20px` | `30px` when used for a margin on an element whose font size is `20px`. |
| `1.2rem` at a `16px` root size | `19.2px`. |
| Accessibility | `rem`-based typography can respond when the root font size changes. |

## Key Takeaways

- `em` and `rem` are **relative CSS units**.
- `em` is useful for component-level sizing that should follow the component's text.
- `rem` is useful for typography and consistent sizing based on the root font size.
- The default root font size is commonly `16px`, but it can change.
- Relative units can help create layouts that respond more naturally to text-size changes.
