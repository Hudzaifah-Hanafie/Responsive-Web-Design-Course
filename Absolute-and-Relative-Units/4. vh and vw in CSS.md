# CSS Viewport Units: `vh` and `vw`

Viewport units let you size elements relative to the browser's **viewport** (the visible area of the page). They are useful when a design needs to respond directly to the available screen width or height.

---

## 1. What Is the Viewport?

The **viewport** is the visible area in which a web page is displayed. Its dimensions can change when, for example:

- The browser window is resized.
- The page is viewed on a device with a different screen size.
- A mobile browser's interface expands or collapses.

Unlike fixed units such as `px`, viewport units are calculated from the viewport's current dimensions.

## 2. The `vh` and `vw` Units

There are two viewport units covered in this note:

| Unit | Meaning | Equal to |
|---|---|---|
| `vh` | Viewport height | 1% of the viewport's height |
| `vw` | Viewport width | 1% of the viewport's width |

For example, if the viewport is 800 pixels tall and 1,200 pixels wide:

- `1vh` is 8 pixels.
- `1vw` is 12 pixels.
- `100vh` is 800 pixels.
- `100vw` is 1,200 pixels.

The key idea is that the value is based on the viewport, not on the element's parent.

### Common Values

- `50vh`: half of the viewport's height.
- `100vh`: the full viewport height.
- `50vw`: half of the viewport's width.
- `100vw`: the full viewport width.

## 3. Using Viewport Units for Full-Screen Sections

A common use for `vh` and `vw` is creating a section that fills the visible browser area. For example, a **hero section** at the top of a page can be sized to occupy the full viewport.

### HTML

```html
<link rel="stylesheet" href="styles.css" />

<section class="hero">
  <h1>100vh / 100vw Example</h1>
  <p>This section fills the entire browser window.</p>
</section>
```

### CSS

```css
body {
  margin: 0;
  font-family: sans-serif;
  border: 5px dashed #333;
}

.hero {
  height: 100vh;
  width: 100vw;
  background-color: #add8e6;
  padding: 2em;
}

.hero h1 {
  font-size: 2em;
  margin-bottom: 0.5em;
}

.hero p {
  font-size: 1em;
}
```

### How It Works

- `height: 100vh` sets the hero's height to 100% of the viewport height.
- `width: 100vw` sets its width to 100% of the viewport width.
- The background color makes the section easy to distinguish.
- `margin: 0` on the body removes the browser's default body margin.

The intention is for the hero section to fill the viewport, regardless of its pixel dimensions.

> **Practical note:** The example also adds `2em` of padding to an element whose width and height are set to `100vw` and `100vh`. With the default CSS box model (`content-box`), padding is added outside those declared dimensions, so the rendered element can become larger than the viewport. If you need the outer box to stay within the viewport dimensions, use `box-sizing: border-box` on the element (or globally).

## 4. Using `vw` for Responsive Typography

Viewport units can also make text scale with the width of the viewport.

### HTML

```html
<link rel="stylesheet" href="styles.css" />

<h1>Responsive Heading</h1>
<p>The h1 heading scales with the viewport width.</p>
```

### CSS

```css
h1 {
  font-size: 5vw;
}
```

Here, `5vw` means that the heading's font size is 5% of the viewport width. As the browser window becomes wider, the font size increases; as it becomes narrower, the font size decreases.

### A Caution About `vw` Text Sizes

A font size based only on `vw` can become:

- **Too small** on narrow screens.
- **Too large** on wide screens.

For that reason, viewport units should be used thoughtfully for typography. In practical designs, consider combining a viewport-based size with a minimum and maximum size—for example, by using CSS `clamp()`:

```css
h1 {
  font-size: clamp(1.5rem, 5vw, 3.5rem);
}
```

This keeps the font size within a defined range while still allowing it to respond to the viewport width.

## 5. How Viewport Units Respond to Resizing

Viewport units are recalculated as the viewport changes. If a user resizes the browser window, elements using `vh` or `vw` adjust to the new dimensions without the page needing to reload.

This makes them useful for fluid layouts, but it also means that an element's size can change while the user is viewing the page.

### Mobile Browser Consideration

On mobile devices, the browser's address bar and other interface elements may appear or disappear as the user scrolls. This can change the available viewport height.

As a result, layouts that rely heavily on `vh` may shift or change size unexpectedly.

> **Important:** Do not assume that the mobile viewport height is always constant. Test full-height sections on actual mobile-sized viewports, and use viewport sizing only where its behavior is appropriate.

## 6. When Should You Use `vh` and `vw`?

| Use case | Possible approach | Why |
|---|---|---|
| Full-height section | `height: 100vh` | Makes the section's height follow the viewport height |
| Full-width section | `width: 100vw` | Makes the section's width follow the viewport width |
| Responsive heading | `font-size: 5vw` | Makes text size respond to viewport width |
| Fluid sizing | Viewport units combined with other CSS sizing techniques | Allows an element to adapt as the viewport changes |

Viewport units are most useful when an element should respond to the **screen's visible dimensions**, rather than simply filling or matching its parent element.

---

## Summary

| Concept | Remember |
|---|---|
| Viewport | The visible area where the page is displayed |
| `vh` | 1% of the viewport height |
| `vw` | 1% of the viewport width |
| `100vh` | Equal to the viewport height |
| `100vw` | Equal to the viewport width |
| Responsive sizing | Viewport-based dimensions update when the viewport changes |
| Mobile behavior | Browser interface changes can affect the viewport height |

## Key Takeaways

- `vh` is based on viewport **height**; `vw` is based on viewport **width**.
- `100vh` and `100vw` are commonly used when creating full-height or full-width sections.
- Viewport units can also make typography scale with the viewport.
- Resizing the browser changes the computed size of elements that use viewport units.
- Text sized only with `vw` may become too small or too large, so consider setting sensible size limits.
- Mobile browser interface changes can affect viewport height, so test layouts on mobile.
- Combine viewport units with other CSS techniques when that produces a more reliable layout.

## Mental Model

Think of the viewport as a measuring ruler that changes with the browser window:

```text
Viewport height
      |
      +-- 1vh   = 1% of that height
      +-- 100vh = all of that height

Viewport width
      |
      +-- 1vw   = 1% of that width
      +-- 100vw = all of that width
```

**In short:** `vh` measures against the viewport's height, while `vw` measures against its width.
