# CSS: Adding Borders Around Images

CSS provides several ways to create borders or border-like effects around images. The most common approaches are:

- `border` — the standard way to add a border around an element.
- Individual border-side properties — useful when each side needs a different style.
- `outline` — creates an outline without affecting the element's dimensions or layout.
- `border-radius` — can be combined with `border` to create rounded corners.

The best approach depends on how much control you need over the appearance and layout of the image.

---

## 1. Using the `border` Property

The simplest way to add a border to an image is with the CSS `border` property.

`border` is a **shorthand property** that lets you specify three main parts of a border at once:

```css
border: width style color;
```

For example:

```html
<link rel="stylesheet" href="styles.css">

<img src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg" alt="A cute cat lying on its back.">
```

```css
img {
  border: 2px solid red;
}
```

### What This Does

This rule adds a:

- **2-pixel** wide border
- **solid** border style
- **red** border color

around all `img` elements.

You can change each part to create different appearances. For example, common border styles include:

- `solid`
- `dashed`
- `dotted`
- `double`

> **Key idea:** The `border` property is usually the best starting point when you simply want a visible border around an image.

---

## 2. Styling Each Border Side Individually

Sometimes you don't want every side of the image to have the same border.

CSS provides separate properties for each side:

| Property | Controls |
|---|---|
| `border-top` | Top border |
| `border-right` | Right border |
| `border-bottom` | Bottom border |
| `border-left` | Left border |

For example:

```html
<link rel="stylesheet" href="styles.css">

<img src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg" alt="A cute cat lying on its back.">
```

```css
img {
  border-top: 10px solid red;
  border-right: 10px dashed green;
  border-bottom: 10px dotted blue;
  border-left: 10px double purple;
}
```

### What This Demonstrates

Each side can have its own:

- width
- style
- color

This gives you much more control than applying one border to the entire image.

> **When to use it:** Use individual border-side properties when different sides need different visual treatments.

---

## 3. Using the `outline` Property

Another way to create a border-like effect is the CSS `outline` property.

It looks similar to a border, but there is an important difference:

> **An outline does not affect the element's dimensions or layout.**

Example:

```html
<link rel="stylesheet" href="styles.css">

<img src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg" alt="A cute cat lying on its back.">
```

```css
img {
  outline: 3px solid gold;
}
```

This creates a **3-pixel solid gold outline** around the image.

### `border` vs. `outline`

| Feature | `border` | `outline` |
|---|---|---|
| Creates a visible edge around an element | Yes | Yes |
| Can specify width, style, and color | Yes | Yes |
| Affects the element's layout/dimensions | Yes | No |
| Useful for a border that should not change layout | — | Yes |

The distinction becomes especially useful when you need a visual boundary without changing how the element is positioned or how much space it occupies.

---

## 4. Adding Rounded Corners with `border-radius`

You can combine `border` with the `border-radius` property to create rounded corners.

Example:

```html
<link rel="stylesheet" href="styles.css">

<img src="https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg" alt="A cute cat lying on its back.">
```

```css
img {
  border: 2px solid black;
  border-radius: 10px;
}
```

### What This Does

The image receives:

- a **2-pixel solid black border**
- **10-pixel rounded corners**

`border-radius` is not itself a border. Instead, it controls the shape of an element's corners and can be combined with a border to change the border's appearance.

> **Important:** `border-radius` is useful when you want a border that follows rounded corners rather than sharp corners.

---

## 5. Choosing the Right Technique

The techniques above can also be combined. The appropriate choice depends on the visual effect and the amount of control you need.

| Goal | Recommended approach |
|---|---|
| Add a simple border around an image | `border` |
| Give each side a different style | `border-top`, `border-right`, `border-bottom`, `border-left` |
| Add a border-like effect without affecting layout | `outline` |
| Create rounded corners | `border-radius` + `border` |
| Create a more customized effect | Combine multiple techniques |

---

## Summary

### `border`

```css
img {
  border: 2px solid red;
}
```

Adds a standard border and lets you control its **width, style, and color**.

### Individual Border Sides

```css
img {
  border-top: 10px solid red;
  border-right: 10px dashed green;
  border-bottom: 10px dotted blue;
  border-left: 10px double purple;
}
```

Allows each side to have its own border settings.

### `outline`

```css
img {
  outline: 3px solid gold;
}
```

Creates an outline without affecting the element's dimensions or layout.

### `border-radius`

```css
img {
  border: 2px solid black;
  border-radius: 10px;
}
```

Adds rounded corners to an element and can be combined with `border`.

---

## Key Takeaways

- **`border` is the simplest and most common way to add a border to an image.**
- The `border` shorthand can define the **width, style, and color** together.
- Individual properties such as `border-top` and `border-left` give you control over each side separately.
- **`outline` creates a border-like visual effect without affecting the element's layout or dimensions.**
- **`border-radius` can be combined with `border` to create rounded corners.**
- These techniques can be **combined and customized** to create different image-border effects.
