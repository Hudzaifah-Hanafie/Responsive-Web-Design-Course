# CSS Background Images: Size, Repeat, Position, and Attachment

CSS provides several properties for controlling how a background image is displayed inside an element.

The main properties covered in this note are:

- `background-image` — chooses the image.
- `background-size` — controls the image's size.
- `background-repeat` — controls whether and how the image repeats.
- `background-position` — controls where the image appears.
- `background-attachment` — controls whether the image scrolls with the page or stays fixed.

> **Mental model:** Think of the background image as a picture placed behind an element. These properties control **which picture**, **how large it is**, **whether it tiles**, **where it sits**, and **whether it moves when the page scrolls**.

---

## 1. Setting a Background Image

The `background-image` property sets an image as the background of an element.

```html
<style>
  body {
    background-image: url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
  }
</style>
```

Here, the image is applied to the `body` element.

### Important

By default, a CSS background image can **repeat horizontally and vertically** to fill the element. The `background-repeat` property can be used to change this behavior.

---

## 2. Controlling Background Image Size

The `background-size` property controls how large the background image is displayed.

Two useful values discussed here are `contain` and `cover`.

### `background-size: contain`

`contain` scales the image as large as possible while keeping its aspect ratio and **without cropping the image**.

```html
<style>
  body {
    background-image: url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
    background-size: contain;
    min-height: 100px;
  }
</style>
```

The `min-height: 100px` gives the element a minimum height so that the background image has space to be visible even when there is very little content.

### `background-size: cover`

`cover` scales the image so that it covers the entire element while maintaining the image's aspect ratio.

```html
<style>
  body {
    background-image: url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
    background-size: cover;
    min-height: 100px;
  }
</style>
```

Because the goal is to **cover the entire element**, some parts of the image may be cropped if the image and element have different aspect ratios.

### `contain` vs. `cover`

| Value | Main goal | Cropping | Aspect ratio |
|---|---|---|---|
| `contain` | Fit the whole image inside the element | No | Preserved |
| `cover` | Fill the entire element | May occur | Preserved |

> **Easy way to remember:** `contain` tries to make the **whole image fit**; `cover` tries to make the **whole element get covered**.

---

## 3. Controlling Background Repetition

The `background-repeat` property controls whether a background image is repeated.

By default, background images repeat **horizontally and vertically**.

### `no-repeat`

Use `no-repeat` when you want the image to appear only once.

```html
<style>
  body {
    background-image: url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
    background-size: contain;
    background-repeat: no-repeat;
    min-height: 100px;
  }
</style>
```

Here, the image will no longer repeat.

### `repeat-x`

Use `repeat-x` to repeat the image **horizontally**.

```html
<style>
  body {
    background-image: url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
    background-size: contain;
    background-repeat: repeat-x;
    min-height: 100px;
  }
</style>
```

### `repeat-y`

Use `repeat-y` to repeat the image **vertically**.

```html
<style>
  body {
    background-image: url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
    background-size: contain;
    background-repeat: repeat-y;
    min-height: 100px;
  }
</style>
```

### Repetition at a Glance

| Value | Behavior |
|---|---|
| Default | Repeats horizontally and vertically |
| `no-repeat` | Does not repeat |
| `repeat-x` | Repeats horizontally |
| `repeat-y` | Repeats vertically |

---

## 4. Positioning the Background Image

The `background-position` property controls **where the background image appears inside the element**.

You can use keywords such as:

- `top`
- `bottom`
- `left`
- `right`
- `center`

You can also use specific pixel or percentage values.

### Example: Center Horizontally, Top Vertically

```html
<style>
  body {
    background-image: url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
    background-size: contain;
    background-repeat: no-repeat;
    background-position: center top;
    min-height: 100px;
  }
</style>
```

The value:

```css
background-position: center top;
```

places the image:

- **Horizontally:** in the center
- **Vertically:** at the top

### Mental Model

When two position keywords are used, think of them as:

```text
horizontal position + vertical position
```

For example:

```css
center top
```

means:

```text
center horizontally
top vertically
```

---

## 5. Controlling Background Scrolling

The `background-attachment` property determines whether the background image moves when the page is scrolled.

The main values covered here are:

- `scroll` — the default behavior; the background image scrolls with the content.
- `fixed` — the background image stays fixed in place while the page is scrolled.

### `background-attachment: fixed`

```html
<style>
  body {
    background-image: url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
    background-position: center top;
    background-attachment: fixed;
  }
</style>
```

With `fixed`, the background image remains in the same position on the screen even when the page is scrolled.

### `scroll` vs. `fixed`

| Value | Behavior |
|---|---|
| `scroll` | Background moves as the page is scrolled |
| `fixed` | Background remains fixed in place while scrolling |

---

## 6. Combining Properties with the `background` Shorthand

Instead of writing several background properties separately, CSS also provides the shorthand `background` property.

For example:

```html
<style>
  body {
    background: center top fixed
      url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
  }
</style>
```

This combines several background settings into one declaration:

```css
background: center top fixed url("...");
```

In this example, it combines:

- `background-position: center top`
- `background-attachment: fixed`
- `background-image: url("...")`

### Why Use the Shorthand?

The shorthand can make CSS more compact when several background properties need to be set together.

For learning, however, it is useful to understand the individual properties first. Once their roles are clear, the shorthand becomes much easier to read.

---

## 7. Putting the Properties Together

The four main properties can be thought of as answering four different questions:

| Property | Question it answers |
|---|---|
| `background-size` | **How large should the image be?** |
| `background-repeat` | **Should the image repeat?** |
| `background-position` | **Where should the image appear?** |
| `background-attachment` | **Should the image move when the page scrolls?** |

Along with `background-image`, these properties give you control over how a background image is displayed.

### Example

```html
<style>
  body {
    background-image: url("https://cdn.freecodecamp.org/curriculum/cat-photo-app/relaxing-cat.jpg");
    background-size: contain;
    background-repeat: no-repeat;
    background-position: center top;
    background-attachment: fixed;
    min-height: 100px;
  }
</style>
```

Read this example as:

1. Use the specified cat image as the background.
2. Scale it using `contain`.
3. Do not repeat it.
4. Place it at the horizontal center and top of the element.
5. Keep it fixed while the page is scrolled.
6. Give the element a minimum height of `100px`.

## Summary

| Property | Purpose | Example values |
|---|---|---|
| `background-image` | Sets the background image | `url("image.jpg")` |
| `background-size` | Controls image scaling | `contain`, `cover` |
| `background-repeat` | Controls image repetition | `no-repeat`, `repeat-x`, `repeat-y` |
| `background-position` | Controls image location | `center top`, `left`, `bottom` |
| `background-attachment` | Controls scrolling behavior | `scroll`, `fixed` |
| `background` | Shorthand for background properties | `center top fixed url("...")` |

---

## Key Takeaways

- **`background-image`** chooses the image used as the background.
- **`background-size: contain`** fits the image inside the element without cropping or stretching it.
- **`background-size: cover`** makes the image cover the entire element while preserving its aspect ratio, which may crop parts of the image.
- Background images **repeat by default** both horizontally and vertically.
- **`background-repeat: no-repeat`** displays the image without repetition.
- **`repeat-x`** repeats horizontally, while **`repeat-y`** repeats vertically.
- **`background-position`** controls where the image is placed inside the element.
- **`background-attachment: scroll`** is the default behavior; **`fixed`** keeps the background in place while scrolling.
- The **`background` shorthand** can combine several background properties into a single declaration.
