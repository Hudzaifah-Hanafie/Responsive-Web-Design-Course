# CSS Background Gradients

CSS gradients create smooth transitions between colors that can be used as an element's background. They can produce visually appealing backgrounds **without requiring image files**.

CSS provides two main types of gradients:

- **Linear gradients** — colors transition along a straight line.
- **Radial gradients** — colors transition outward from an origin, usually in a circular or elliptical shape.

---

## 1. Linear Gradients

A **linear gradient** transitions between colors along a straight line. You can control the direction of that line and specify the colors used in the transition.

### Basic Syntax

```css
background: linear-gradient(direction, color-stop1, color-stop2, ...);
```

The `linear-gradient()` function is used as the value of the CSS `background` property.

### Direction

The `direction` determines which way the gradient runs. It can be specified using:

- An angle, such as `45deg`
- A direction keyword, such as `to right` or `to bottom`
- A side or corner

### Color Stops

A **color stop** specifies a color used in the gradient and can optionally specify its position in the gradient.

For example:

```css
linear-gradient(to right, red, yellow);
```

This creates a transition from `red` to `yellow`.

### Example

HTML:

```html
<link rel="stylesheet" href="styles.css">
<div class="linear-gradient"></div>
```

CSS:

```css
.linear-gradient {
  background: linear-gradient(to right, red, yellow);
  height: 40vh;
}
```

### How It Works

The important part is:

```css
background: linear-gradient(to right, red, yellow);
```

Here:

- `linear-gradient()` creates a linear gradient.
- `to right` makes the gradient run horizontally from left to right.
- `red` is the starting color.
- `yellow` is the ending color.

The element also has:

```css
height: 40vh;
```

`vh` is a viewport-relative unit. In this example, `40vh` makes the element's height equal to `40%` of the viewport height. The details of `vh` units are covered in a later lesson.

> **Mental model:** Imagine drawing a straight line across the element. The colors change gradually along that line.

---

## 2. Radial Gradients

A **radial gradient** transitions between colors outward from an origin. Instead of following a straight line, the transition spreads outward in a **circular or elliptical shape**.

### Basic Syntax

```css
background: radial-gradient(shape size at position, color-stop1, color-stop2, ...);
```

A radial gradient can be understood by breaking its syntax into three main parts:

1. **Shape** — the shape of the gradient.
2. **Size** — how far the gradient extends.
3. **Position** — where the gradient originates.

Color stops then define the colors used throughout the transition.

### Shape

The `shape` determines the form of the gradient.

The available shapes are:

- `circle`
- `ellipse`

### Size

The `size` determines how large the gradient's ending shape is.

Common keywords include:

- `closest-side`
- `closest-corner`
- `farthest-side`
- `farthest-corner`

These keywords determine how the gradient's ending shape relates to the sides or corners of the element.

### Position

The `position` determines the location of the gradient's center.

It can be specified with keywords such as:

- `center`
- `top left`
- `bottom right`

Or with precise values such as:

```css
50% 50%
10px 20px
```

### Color Stops

Color stops are the colors that the gradient transitions through.

A color stop can optionally include a position, specified using a percentage or length, to control where that color appears in the gradient.

### Example

HTML:

```html
<link rel="stylesheet" href="styles.css">
<div class="radial-gradient"></div>
```

CSS:

```css
.radial-gradient {
  background: radial-gradient(circle closest-side at center, red, yellow 50%, green);
  height: 60vh;
}
```

### How It Works

The gradient definition is:

```css
radial-gradient(circle closest-side at center, red, yellow 50%, green)
```

Breaking it down:

| Part | Meaning |
| --- | --- |
| `circle` | Uses a circular gradient shape. |
| `closest-side` | Makes the gradient's ending shape fit the closest side of the element. |
| `at center` | Places the gradient's center in the middle of the element. |
| `red` | The starting color at the center. |
| `yellow 50%` | Places `yellow` at 50% of the gradient's radius. |
| `green` | The final color in the transition. |

The element has a height of:

```css
height: 60vh;
```

This makes its height equal to `60%` of the viewport height.

> **Mental model:** Imagine a point at the center of the element. The colors spread outward from that point, forming rings of color.

---

## 3. Linear vs. Radial Gradients

The main difference is **the direction in which the color transition spreads**.

| Gradient type | Color transition | Typical shape |
| --- | --- | --- |
| `linear-gradient()` | Along a straight line | Linear |
| `radial-gradient()` | Outward from an origin | Circular or elliptical |

### Choosing Between Them

Use a **linear gradient** when you want the color transition to move from one side or corner of an element toward another.

Use a **radial gradient** when you want the transition to spread outward from a particular point.

---

## 4. Understanding Color Stops

Color stops are important because they control **which colors appear and where the transitions occur**.

For example:

```css
linear-gradient(to right, red, yellow);
```

uses two colors without explicitly specifying positions.

A gradient can also include a color-stop position:

```css
radial-gradient(circle, red, yellow 50%, green);
```

Here, `yellow 50%` indicates that `yellow` is positioned at `50%` of the gradient's radius.

> **Important:** Color stops do not simply represent a list of unrelated colors. They define points in the gradient between which CSS creates smooth color transitions.

---

## 5. Practical Examples

### Simple Linear Background

```css
background: linear-gradient(to right, red, yellow);
```

**Result:** A horizontal transition from `red` on the left to `yellow` on the right.

### Centered Radial Background

```css
background: radial-gradient(circle at center, red, yellow, green);
```

**Result:** Colors transition outward from the center in a circular pattern.

The original material demonstrates the more explicit form:

```css
background: radial-gradient(circle closest-side at center, red, yellow 50%, green);
```

This version additionally controls the gradient's shape, size, center position, and the position of the `yellow` color stop.

## Summary

| Concept | Key idea |
| --- | --- |
| CSS gradient | A smooth transition between two or more colors. |
| `linear-gradient()` | Creates a gradient along a straight line. |
| `radial-gradient()` | Creates a gradient that radiates outward from an origin. |
| Direction | Controls the direction of a linear gradient. |
| Shape | Controls whether a radial gradient is a `circle` or `ellipse`. |
| Size | Controls how far a radial gradient extends. |
| Position | Controls the location of a radial gradient's center. |
| Color stop | Defines a color and, optionally, its position in the gradient. |
| `vh` | A viewport-relative unit used in the examples to set element height. |

---

## Key Takeaways

- **CSS gradients allow smooth color transitions without using image files.**
- There are two main types covered here: **linear** and **radial** gradients.
- A **linear gradient** follows a straight line.
- A **radial gradient** spreads outward from an origin.
- Gradient **direction, shape, size, position, and color stops** determine how the final gradient looks.
- Color stops can include positions to give more control over where colors appear.
- The `background` property is used in these examples to apply the gradient to an element.
