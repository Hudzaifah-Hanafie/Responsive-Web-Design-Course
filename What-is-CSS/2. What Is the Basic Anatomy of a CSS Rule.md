CSS (Cascading Style Sheets) controls the visual presentation of a web page. These styles are built using individual **CSS rules**.

---

## 1. High-Level Anatomy

A CSS rule consists of two main components: a **Selector** and a **Declaration Block**.

```css
selector {
  property: value;
}
```

* **Selector**: Identifies and targets the HTML element(s) to style.
* **Declaration Block**: The area wrapped in curly braces `{}` that contains one or more style declarations.

---

## 2. Breakdown of Components

| Component | Description | Example |
| :--- | :--- | :--- |
| **Selector** | Identifies the HTML target. | `p`, `.subheading`, `#title` |
| **Declaration Block** | Contains all styles applied to the selector. | `{ color: blue; }` |
| **Property** | Specifies the CSS feature being styled. | `color`, `background-color` |
| **Value** | The setting applied to the property. | `blue`, `purple`, `navy` |

> **Syntax Rules:**
> * A **colon** (`:`) must separate the property and the value.
> * A **semicolon** (`;`) must end each declaration inside the block.

---

## 3. Basic Example: Single Selector

Targets all paragraph elements (`<p>`) on a web page and changes their text color to blue.

### HTML
```html
<link rel="stylesheet" href="styles.css">
<h1>Learning about CSS</h1>

<p>Example paragraph element</p>
<p>Another example paragraph element</p>
```

### CSS
```css
p {
  color: blue;
}
```

---

## 4. Selector Types & Grouping

CSS supports various selector types to target elements in different ways:

* **Type Selector**: Targets HTML tags directly (e.g., `p`, `h1`).
* **ID Selector**: Targets a unique element with a specific `id`. **Must start with `#`**.
* **Class Selector**: Targets elements with a specific `class`. **Must start with `.`**.

### Grouping Selectors
To apply identical styles to multiple selectors at once, separate each selector with a **comma** (`,`).

#### HTML
```html
<link rel="stylesheet" href="styles.css">

<h1 id="title">Example heading</h1>
<h2 class="subheading">Example subheading</h2>
<p>This paragraph is not affected by the selector.</p>
```

#### CSS
```css
#title,
.subheading {
  color: navy;
}
```

In this example, both the element with `id="title"` and any element with `class="subheading"` will have their text color changed to `navy`. The paragraph tag remains unaffected.
