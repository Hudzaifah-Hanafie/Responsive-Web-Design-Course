# CSS Application Methods

CSS can be applied to an HTML document in **three main ways**:

1. **Inline CSS** — written directly on an HTML element.
2. **Internal CSS** — written inside a `<style>` element in the HTML document.
3. **External CSS** — written in a separate `.css` file and linked to the HTML document.

Each method has a different purpose. The important skill is not just knowing how each method works, but understanding **when to use each one**.

> **General rule:** For most real-world projects, especially larger ones, **external CSS is the preferred approach** because it keeps HTML and CSS separate and makes styles easier to reuse and maintain.

---

## 1. Inline CSS

### What Is Inline CSS?

**Inline CSS** is written directly inside an HTML element using the `style` attribute.

Because the style is attached directly to the element, it applies specifically to that element.

### Example

```html
<p style="color: green;">This is an inline-styled paragraph.</p>
```

Here, the `style` attribute sets the paragraph's text color to `green`.

### When to Use Inline CSS

Inline CSS can be useful for:

- Quick, one-off styles.
- Applying a style to a specific element.
- Situations where you need to override other styles for a particular element.

### Limitations

Inline CSS should generally be **avoided for most styling work** because it:

- Clutters the HTML.
- Makes the HTML harder to read.
- Makes styles harder to maintain.
- Does not encourage reuse across multiple elements or pages.

> **Practical rule:** If you find yourself writing the same style repeatedly in multiple `style` attributes, move that styling into internal or, preferably, external CSS.

---

## 2. Internal CSS

### What Is Internal CSS?

**Internal CSS** is written inside a `<style>` element, usually within the `<head>` section of an HTML document.

It can be used to style elements throughout that particular HTML page.

### Example

```html
<head>
  <style>
    p {
      color: blue;
    }
  </style>
</head>

<body>
  <p>This paragraph is styled using internal CSS.</p>
</body>
```

In this example, the CSS rule:

```css
p {
  color: blue;
}
```

applies blue text to all `<p>` elements on that page.

### When to Use Internal CSS

Internal CSS is useful when:

- You are styling a single HTML document.
- The styles are specific to that page.
- The styles do not need to be reused across multiple pages.

For example, a small single-page website may use internal CSS when keeping the styles in a separate file would provide little benefit.

### Limitations

Internal CSS has some disadvantages:

- The styles are not easily reusable across multiple HTML pages.
- HTML and CSS remain in the same file.
- Larger documents can become harder to maintain as the amount of CSS grows.

> **Think of internal CSS as page-level styling:** it is more organized than inline CSS, but it is still tied to one HTML document.

---

## 3. External CSS

### What Is External CSS?

**External CSS** is written in a separate `.css` file and linked to an HTML document using the `<link>` element.

This approach separates the page's **structure** from its **styling**.

### Example

First, link the external stylesheet from the HTML document:

```html
<head>
  <link rel="stylesheet" href="styles.css">
</head>

<body>
  <p>This paragraph is styled using external CSS.</p>
</body>
```

Then, define the styles in `styles.css`:

```css
p {
  color: red;
}
```

The HTML document contains the structure, while the CSS file contains the styling.

### Understanding `rel` and `href`

When linking an external stylesheet, the `<link>` element uses attributes such as `rel` and `href`.

```html
<link rel="stylesheet" href="styles.css">
```

#### `rel`

The `rel` attribute describes the **relationship between the current HTML document and the linked resource**.

For a CSS stylesheet:

```html
rel="stylesheet"
```

This tells the browser that the linked resource is a stylesheet.

#### `href`

The `href` attribute specifies the **URL or path of the resource** that should be retrieved.

```html
href="styles.css"
```

In this case, the browser looks for the `styles.css` file at the specified path.

### When to Use External CSS

External CSS is ideal when:

- A project contains multiple HTML pages.
- The same styles need to be reused.
- You want a consistent design across pages.
- You are working on a larger project.
- You want to keep HTML and CSS clearly separated.

### Why External CSS Is Preferred

External CSS promotes **separation of concerns**:

| Responsibility | Technology |
|---|---|
| Page structure and content | HTML |
| Visual styling and presentation | CSS |

This separation makes a project:

- Easier to read.
- Easier to maintain.
- Easier to reuse.
- Easier to scale as the project grows.

---

## 4. Comparing the Three Methods

| Method | Where CSS is written | Typical scope | Main use case | Maintainability |
|---|---|---|---|---|
| **Inline** | `style` attribute on an HTML element | Individual element | Quick, one-off styling or specific overrides | Low |
| **Internal** | `<style>` inside the HTML document | One page | Styles specific to a single document | Medium |
| **External** | Separate `.css` file | Multiple pages | Reusable and consistent project-wide styling | High |

### Simple Mental Model

Think of the three methods in terms of **where the styling lives**:

```text
INLINE
HTML element
    ↓
One specific element

INTERNAL
HTML document
    ↓
One specific page

EXTERNAL
Separate CSS file
    ↓
Multiple pages / larger project
```

As the project becomes larger, moving CSS out of individual HTML elements and into reusable stylesheets generally makes the code easier to manage.

---

## 5. Which Method Should You Choose?

A simple decision process is:

```text
Do you need a quick style for one specific element?
        │
        └── Yes → Inline CSS may be appropriate.

Is the styling only needed for one HTML page?
        │
        └── Yes → Internal CSS may be appropriate.

Does the styling need to be reused or shared across pages?
        │
        └── Yes → Use External CSS.
```

In practice, **external CSS should usually be your default choice**, particularly for larger or more complex projects.

---

## Summary

| CSS Method | Key Idea |
|---|---|
| **Inline CSS** | Style an individual HTML element directly with the `style` attribute. |
| **Internal CSS** | Put page-specific styles inside a `<style>` element in the HTML document. |
| **External CSS** | Put styles in a separate `.css` file and connect it with `<link>`. |

---

## Key Takeaways

- CSS can be applied using **inline, internal, or external CSS**.
- **Inline CSS** is attached directly to an HTML element through the `style` attribute.
- Inline CSS is useful for quick, one-off styles but can make HTML difficult to maintain.
- **Internal CSS** is placed inside a `<style>` element and is useful for styling a single HTML document.
- **External CSS** is stored in a separate `.css` file and linked with `<link>`.
- The `<link>` element uses `rel="stylesheet"` to describe the linked resource as a stylesheet.
- The `href` attribute specifies where the stylesheet can be found.
- External CSS promotes **separation of concerns** between HTML structure and CSS styling.
- For most larger projects, **external CSS is the preferred approach** because it improves reuse, consistency, maintainability, and scalability.
