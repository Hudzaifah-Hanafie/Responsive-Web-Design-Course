# CSS Width and Height

CSS provides several properties for controlling the dimensions of elements. The main properties are:

- `width` — controls an element's width.
- `height` — controls an element's height.
- `min-width` — sets the smallest width an element can have.
- `min-height` — sets the smallest height an element can have.
- `max-width` — sets the largest width an element can have.
- `max-height` — sets the largest height an element can have.

These properties can use different CSS units, such as pixels (`px`), percentages (`%`), viewport units (`vw`, `vh`), and others.

---

## 1. `width`

The `width` property specifies how wide an element should be.

If you do not explicitly set `width`, its default value is `auto`. With `auto`, the browser determines the element's width based on factors such as:

- its content,
- its parent container, and
- its display type.

For a typical `div`, `width: auto` allows it to expand to fill the available width of its parent container.

### Example

```html
<head>
  <style>
    .box {
      width: 100px;
      height: 100px;
      background-color: skyblue;
    }
  </style>
</head>
<body>
  <div class="box"></div>
</body>
```

In this example, the `.box` element has:

- a width of `100px`,
- a height of `100px`, and
- a `skyblue` background.

So the box is `100px × 100px`.

### Pixels (`px`)

A pixel (`px`) is a fixed-size CSS unit that provides precise control over an element's dimensions.

For example:

```css
.box {
  width: 100px;
  height: 100px;
}
```

---

## 2. `height`

The `height` property specifies how tall an element should be.

Like `width`, its default value is `auto`. This allows the browser to determine the element's height based on its content and layout.

```css
.box {
  height: 100px;
}
```

When learning CSS dimensions, it is useful to distinguish between:

- **Explicit dimensions** — such as `width: 100px`.
- **Automatic dimensions** — such as `width: auto` or `height: auto`.

---

## 3. `min-width` and `min-height`

Minimum-size properties prevent an element from becoming smaller than a specified value.

### `min-width`

`min-width` specifies the **smallest width** an element is allowed to have.

Even if another rule would make the element narrower, it will not shrink below the `min-width` value.

### `min-height`

`min-height` specifies the **smallest height** an element is allowed to have.

It prevents the element from becoming shorter than the specified value.

### Example

```html
<head>
  <style>
    .box {
      width: 50px;
      min-width: 100px;
      height: 50px;
      min-height: 100px;
      background-color: lightcoral;
    }
  </style>
</head>
<body>
  <div class="box"></div>
</body>
```

Although `width` and `height` are both set to `50px`, the box will actually be `100px × 100px`.

Why?

Because the minimum dimensions are larger:

```text
width:      50px
min-width: 100px  → minimum wins

height:      50px
min-height: 100px  → minimum wins
```

> **Important:** `min-width` and `min-height` prevent the element from becoming smaller than their specified values.

### When to use minimum dimensions

Minimum dimensions are useful when an element needs to remain usable or visually consistent even when its normal size would otherwise become too small.

---

## 4. `max-width` and `max-height`

Maximum-size properties prevent an element from growing beyond a specified value.

### `max-width`

`max-width` specifies the **largest width** an element can have.

Even if the normal `width` value is larger, the element cannot exceed `max-width`.

### `max-height`

`max-height` specifies the **largest height** an element can have.

It prevents the element from growing taller than the specified maximum.

### Example

```html
<head>
  <style>
    .box {
      width: 200px;
      max-width: 150px;
      height: 200px;
      max-height: 150px;
      background-color: lightgreen;
    }
  </style>
</head>
<body>
  <div class="box"></div>
</body>
```

The element has:

```text
width:      200px
max-width: 150px  → maximum wins

height:      200px
max-height: 150px  → maximum wins
```

Therefore, the actual dimensions are `150px × 150px`.

> **Important:** `max-width` and `max-height` prevent an element from becoming larger than their specified values.

---

## 5. How the Dimension Constraints Work Together

A useful way to think about these properties is:

- `width` / `height` → the **preferred or normal dimension**
- `min-width` / `min-height` → the **lower limit**
- `max-width` / `max-height` → the **upper limit**

Conceptually:

```text
minimum                         maximum
   │                               │
   ▼                               ▼
   ├──────── preferred size ────────┤
   │                               │
 min-width /                    max-width /
 min-height                     max-height
```

For example:

```css
.box {
  width: 600px;
  min-width: 300px;
  max-width: 500px;
}
```

The requested width is `600px`, but the maximum allowed width is `500px`, so the element is limited to `500px`.

Likewise:

```css
.box {
  width: 200px;
  min-width: 300px;
}
```

The requested width is `200px`, but the minimum allowed width is `300px`, so the element cannot be smaller than `300px`.

### Practical mental model

Think of `width` as the **target**, while `min-width` and `max-width` define the boundaries:

```text
        cannot go smaller       cannot go larger
               │                       │
               ▼                       ▼
          min-width ── width ── max-width
```

The same idea applies vertically:

```text
       min-height ── height ── max-height
```

This makes these properties especially useful for responsive layouts, where an element may need to grow or shrink while still staying within reasonable limits.

---

## Summary

| Property | Purpose | Think of it as |
|---|---|---|
| `width` | Sets the element's width | Normal/preferred width |
| `height` | Sets the element's height | Normal/preferred height |
| `min-width` | Sets the smallest allowed width | Lower width limit |
| `min-height` | Sets the smallest allowed height | Lower height limit |
| `max-width` | Sets the largest allowed width | Upper width limit |
| `max-height` | Sets the largest allowed height | Upper height limit |

### Example

```css
.box {
  width: 600px;
  min-width: 300px;
  max-width: 500px;

  height: 400px;
  min-height: 200px;
  max-height: 350px;
}
```

The important idea is that the final size is constrained by the minimum and maximum values:

- The width cannot be less than `300px` or greater than `500px`.
- The height cannot be less than `200px` or greater than `350px`.
- The normal `width` and `height` values are used when they fall within those limits.

---

## Key Takeaways

1. **`width` and `height` control an element's normal dimensions.**
2. If `width` or `height` is not specified, its default value is `auto`.
3. **`min-width` and `min-height` establish lower limits** and prevent elements from becoming too small.
4. **`max-width` and `max-height` establish upper limits** and prevent elements from becoming too large.
5. When a normal dimension falls outside its allowed range, the minimum or maximum constraint limits the final size.
6. A useful mental model is:
   - `width` / `height` = desired size
   - `min-*` = minimum boundary
   - `max-*` = maximum boundary
7. These constraints are particularly useful for keeping layouts usable and controlling how elements behave as available space changes.
