# Linear and Radial Gradients in CSS

CSS gradients create smooth transitions between two or more colors. They are useful for adding depth, texture, and visual interest to a design without needing a separate image file.

CSS provides two main gradient types:

- **Linear gradients** blend colors along a straight line.
- **Radial gradients** blend colors outward from a central point, producing a circular or elliptical effect.

This note explains how each type works, how to control its direction or shape, and how to position color stops precisely.

## 1. Linear Gradients

A **linear gradient** transitions between colors along a straight line. The line's direction determines where the colors begin and end.

### Basic syntax

```css
background: linear-gradient(direction, color1, color2, ...);
```

- `direction` controls the direction in which the gradient runs.
- The color arguments define the colors being blended.
- You can provide two or more colors.

### Example: left to right

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<div class="linear-gradient"></div>
```

CSS:

```css
.linear-gradient {
  background: linear-gradient(to right, red, blue);
  height: 40vh;
}
```

The result transitions from **red on the left** to **blue on the right**. The `to right` value sets the gradient's direction.

### Controlling direction

Common direction values include:

| Value | Direction |
|---|---|
| `to right` | Left to right |
| `to left` | Right to left |
| `to top` | Bottom to top |
| `to bottom` | Top to bottom |

You can also use an angle, such as `45deg`, to set a diagonal direction.

### Using multiple colors

A linear gradient can contain more than two colors. Each color becomes a **color stop** along the gradient line.

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<div class="multi-color-gradient"></div>
```

CSS:

```css
.multi-color-gradient {
  background: linear-gradient(to right, red, yellow, blue);
  height: 40vh;
}
```

This produces a transition from red to yellow to blue. When no stop positions are supplied, the browser distributes the color stops evenly.

### Setting precise color-stop positions

You can place color stops at specific positions using percentages.

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<div class="precise-gradient"></div>
```

CSS:

```css
.precise-gradient {
  background: linear-gradient(to right, red 20%, yellow 40%, blue 80%);
  height: 40vh;
}
```

In this example:

- Red is assigned to the `20%` position.
- Yellow is assigned to the `40%` position.
- Blue is assigned to the `80%` position.

The browser blends between the specified stops. The positions control where each stop occurs along the gradient line; they are not separate widths of solid color.

## 2. Radial Gradients

A **radial gradient** transitions outward from a central point. Its shape can be circular or elliptical.

### Basic syntax

```css
background: radial-gradient(shape, color1, color2, ...);
```

The first argument can specify the gradient's shape. The colors define the transition from the center outward.

### Example: circular gradient

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<div class="radial-gradient"></div>
```

CSS:

```css
.radial-gradient {
  background: radial-gradient(circle, red, blue);
  height: 40vh;
}
```

This creates a circular gradient that starts with red in the center and transitions to blue toward the outer edge.

### Controlling shape and position

You can specify both the shape and the position from which the gradient radiates.

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<div class="custom-radial-gradient"></div>
```

CSS:

```css
.custom-radial-gradient {
  background: radial-gradient(ellipse at top left, red, blue);
  height: 40vh;
}
```

Here:

- `ellipse` makes the gradient elliptical rather than circular.
- `at top left` places its starting point at the top-left of the element.
- Red is at the center/origin, transitioning to blue farther away.

### Visual explanation

![[12-Radial-Gradient-Shape-and-Origin.excalidraw]]

A radial gradient spreads from its origin. A circle has equal dimensions in every direction; an ellipse is wider or taller in one direction.

## 3. Color Stops in Gradients

Both linear and radial gradients support color stops at precise positions. A stop identifies where a particular color is placed along the gradient.

For example:

```css
background: linear-gradient(to right, red 20%, yellow 40%, blue 80%);
```

The percentages position the stops along the gradient. This gives you more control than relying on the browser's default even distribution.

Use positioned color stops when you need to control where a color transition occurs—for example, to make one color occupy more of a background or to align a transition with a particular part of a design.

## 4. Where CSS Gradients Can Be Used

Gradients can be used anywhere CSS accepts an image value. Common uses include:

- **Backgrounds:** add color transitions to page sections or containers.
- **Buttons:** make interactive elements more visually distinctive.
- **Text effects:** combine gradients with other CSS properties to create gradient-colored text.

Because gradients are defined in CSS, they can provide these visual effects without requiring a separate image asset.

## 5. Accessibility: Maintain Sufficient Contrast

A visually attractive gradient is not automatically easy to read.

When placing text over a gradient, check that the text has sufficient contrast against the background **across the entire area where the text appears**. A gradient changes color from one region to another, so a text color that is readable at one point may become difficult to read elsewhere.

> **Practical check:** Review the text against the lightest, darkest, and most saturated parts of the gradient—not just one spot.

## Summary

| Concept | Linear gradient | Radial gradient |
|---|---|---|
| How colors transition | Along a straight line | Outward from a central point |
| Main controls | Direction and color stops | Shape, origin/position, and color stops |
| Typical shapes | Horizontal, vertical, diagonal | Circular or elliptical |
| Example | `linear-gradient(to right, red, blue)` | `radial-gradient(circle, red, blue)` |

## Key Takeaways

- A CSS gradient blends two or more colors smoothly.
- `linear-gradient()` creates a transition along a straight line; its direction can use keywords such as `to right` or an angle such as `45deg`.
- `radial-gradient()` creates a transition that radiates outward; it can be circular or elliptical and can be positioned, such as `at top left`.
- Color stops can be given percentage positions to control where colors occur.
- Gradients can be used for backgrounds, buttons, and text effects without a separate image file.
- Always check text contrast when using a gradient behind content.

## Mental Model

Think of the two gradient types by asking **which path does the color transition follow?**

- **Linear:** follow a straight line from one side toward the other.
- **Radial:** move outward from a central origin toward the surrounding area.
