# Named Colors in CSS

CSS colors help shape the appearance of a web page. They affect readability, visual hierarchy, mood, and the overall user experience.

One simple way to specify a color is to use a **CSS named color**: a predefined color name that browsers recognize.

## 1. What Are Named Colors?

Named colors are predefined names that represent colors in CSS. Examples include:

- `red`
- `blue`
- `yellow`
- `aqua`
- `fuchsia`
- `black`
- `navy`
- `lightgray`

The original lesson describes the collection as **140 standard color names**. Because the names are descriptive, they can make a stylesheet easier to read at a glance.

### A first example

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<p>This is a paragraph.</p>
```

CSS (`styles.css`):

```css
p {
  color: red;
}
```

The `color` property controls the text color. Here, `red` is the named color assigned as its value, so the paragraph text appears red.

## 2. Using Named Colors for Text and Backgrounds

Named colors can be used with CSS properties that accept color values. For example, `color` sets text color, while `background-color` sets an element's background color.

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<h1>This is a heading</h1>
```

CSS (`styles.css`):

```css
h1 {
  color: navy;
  background-color: lightgray;
}
```

In this example:

- `color: navy;` makes the heading text navy.
- `background-color: lightgray;` gives the heading a light-gray background.

The names make the intent of the styles easy to understand without needing to interpret a numeric color value.

## 3. How to Think About a Named Color

A useful mental model is:

1. Choose a CSS property that accepts a color.
2. Give that property a recognized color name as its value.
3. The browser uses that value when rendering the element.

For example, `color: red` means “render this element's text using the named color `red`.”

## 4. When Are Named Colors Useful?

Named colors are especially convenient for:

- **Quick prototyping:** apply a recognizable color without looking up a color code.
- **Simple designs:** use a straightforward palette when exact shade control is not important.
- **Readable stylesheets:** communicate the intended color directly through a descriptive name.

For small examples and early experiments, names such as `red`, `navy`, and `lightgray` are quick to write and easy to recognize.

## 5. Limitations of Named Colors

Named colors are convenient, but the set of available names is limited. The original lesson describes 140 options. A design may need a shade that does not correspond closely to one of those predefined names.

This makes named colors less suitable when a design requires **precise color control** or a more detailed range of shades.

### Choosing a color notation

| Situation | A useful approach |
|---|---|
| You need a quick, recognizable color | A named color can be convenient |
| You are prototyping or making a simple design | Named colors are often sufficient |
| You need a very specific shade | Consider a more precise color model, such as RGB or HSL |

RGB and HSL are mentioned here as alternatives for more detailed color control; their syntax and behavior are topics for later lessons.

## 6. Summary

| Concept | What to remember |
|---|---|
| Named color | A predefined CSS color name recognized by browsers |
| Example values | `red`, `blue`, `navy`, `lightgray` |
| `color` | Sets text color |
| `background-color` | Sets background color |
| Main strengths | Simple, descriptive, and convenient for quick styling |
| Main limitation | Limited selection; may not provide the exact shade a design needs |
| Alternatives | RGB and HSL offer more detailed ways to specify colors |

## Key Takeaways

- CSS named colors are predefined color names that browsers recognize.
- Use a named color as the value of a CSS color property, such as `color` or `background-color`.
- Named colors are easy to read and useful for prototyping and simple designs.
- Use a more precise color notation, such as RGB or HSL, when the available names do not provide the shade you need.
