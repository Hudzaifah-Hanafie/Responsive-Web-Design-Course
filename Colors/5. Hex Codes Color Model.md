# Hex Codes and the RGB Color Model in CSS

Hexadecimal color values (usually called **hex codes**) are a common way to specify colors in CSS. They provide a compact, precise representation of colors using the **RGB color model**: red, green, and blue.

This note explains how to read a hex code, how its values combine to produce a color, how to use it in CSS, and when the shorter three-digit form is available.

## 1. What Is a Hex Color Code?

A **hex color code** is a value written with the hexadecimal, or **base-16**, numbering system. In CSS, the familiar six-digit form begins with a hash symbol (`#`) and is followed by six hexadecimal characters.

Hexadecimal uses sixteen symbols:

- Digits `0` through `9`
- Letters `A` through `F`

For a standard six-digit CSS hex color, the six characters are grouped into three pairs:

| Part | Represents | Meaning |
|---|---|---|
| `RR` | Red | Intensity of the red channel |
| `GG` | Green | Intensity of the green channel |
| `BB` | Blue | Intensity of the blue channel |

The general pattern is:

```css
#RRGGBB
```

`RR`, `GG`, and `BB` are placeholders, not literal letters you normally type. Replace them with the hexadecimal values for the color you want.

Each pair controls one color channel. The three channel values are combined to produce the final color.

## 2. Understanding the Values

Each two-character pair can range from `00` to `FF`:

- `00` means the channel has the lowest intensity.
- `FF` means the channel has the highest intensity.
- Values between them represent intermediate intensities.

In the usual 8-bit RGB interpretation, each pair corresponds to a decimal value from 0 to 255. You do not need to convert every value manually to use hex colors, but knowing the range helps explain why the pairs can represent different levels of intensity.

### Examples: black and white

| Hex code | Red | Green | Blue | Result |
|---|---:|---:|---:|---|
| `#000000` | `00` | `00` | `00` | Black: all channels at minimum |
| `#FFFFFF` | `FF` | `FF` | `FF` | White: all channels at maximum |

### Example: reading `#FF5733`

`#FF5733` is a reddish-orange color. Split it into its three pairs:

| Pair | Channel | Interpretation |
|---|---|---|
| `FF` | Red | Highest intensity |
| `57` | Green | Moderate intensity |
| `33` | Blue | Relatively low intensity |

The red channel is strongest, the green channel contributes a moderate amount, and the blue channel contributes less. Together, these values produce the reddish-orange color.

### Example: reading `#4CAF50`

`#4CAF50` is a shade of green:

| Pair | Channel | Interpretation |
|---|---|---|
| `4C` | Red | Low intensity |
| `AF` | Green | Strong intensity |
| `50` | Blue | Moderate intensity |

The green channel is strongest, which is why the resulting color appears green.

## 3. Using Hex Codes in CSS

A hex code can be used as the value of CSS color properties. Common examples include:

- `color` for text color
- `background-color` for an element's background
- `border-color` for a border

### HTML

```html
<link rel="stylesheet" href="styles.css" />

<h1>This is a heading.</h1>
<p>This is a paragraph.</p>
```

### CSS

```css
h1 {
  color: #FF5733; /* A reddish-orange text color */
}

p {
  background-color: #4CAF50; /* A shade of green */
}
```

The heading receives the reddish-orange text color. The paragraph receives a green background.

### Another CSS example

HTML:

```html
<link rel="stylesheet" href="styles.css" />

<button>Example</button>
```

CSS:

```css
body {
  background-color: #F0F0F0; /* Light gray background */
}

button {
  background-color: #007BFF; /* A shade of blue */
  color: #FFFFFF; /* White text */
}
```

Here, the page background is light gray. The button has a blue background and white text.

**Why use hex codes?** They let you specify exact color values, which is useful when you want colors to remain consistent across different parts of a website or application.

## 4. Three-Digit Hex Shorthand

CSS also supports a shorter three-digit form: `#RGB`.

The shorthand is valid when **both characters in each pair are identical**. Each single digit is duplicated to form its corresponding two-character pair.

For example:

- `#FFF` expands to `#FFFFFF`.
- `#000` expands to `#000000`.
- `#ABC` expands to `#AABBCC`.

![[10-Hex-Shorthand.excalidraw]]

A value such as `#FF5733` cannot be shortened to three digits because its pairs (`FF`, `57`, and `33`) do not all consist of repeated identical characters.

### CSS example

```html
<link rel="stylesheet" href="styles.css" />

<h2>This is a heading.</h2>
```

```css
body {
  background-color: #000;
}

h2 {
  color: #FFF; /* White, equivalent to #FFFFFF */
}
```

The shorthand `#FFF` produces the same color as `#FFFFFF`, and `#000` produces the same color as `#000000`.

## 5. Why Developers Use Hex Codes

Hex codes are popular because they are:

- **Precise:** a specific value can be reused wherever the same color is needed.
- **Compact:** the six-digit form is relatively short, and some colors can use three-digit shorthand.
- **Widely supported:** CSS hex colors work across modern browsers.
- **Convenient with design tools:** tools such as Adobe Photoshop and Figma can provide hex values for selected colors, which can then be copied into CSS.

They are especially useful when:

- Matching exact brand or design-system colors.
- Reusing consistent colors across a website.
- Copying a color value from design software.
- Choosing a specific shade that is not conveniently represented by a named CSS color.

The six-digit RGB form can represent more than 16 million combinations (256 possible values for each of the three channels).

## Summary

| Idea | Remember |
|---|---|
| Hexadecimal | A base-16 number system using `0`–`9` and `A`–`F` |
| Six-digit CSS hex | Written as `#RRGGBB` |
| `RR` | Red channel intensity |
| `GG` | Green channel intensity |
| `BB` | Blue channel intensity |
| `00` | Lowest channel intensity |
| `FF` | Highest channel intensity |
| `#000000` | Black |
| `#FFFFFF` | White |
| Three-digit shorthand | `#RGB`, where each digit is duplicated |
| CSS usage | Can be used with properties such as `color` and `background-color` |

## Key Takeaways

1. A CSS hex color is a hexadecimal representation of an RGB color.
2. In `#RRGGBB`, the first pair controls red, the second green, and the third blue.
3. Each pair ranges from `00` (minimum) to `FF` (maximum).
4. The three channel values combine to create the final color.
5. The three-digit form `#RGB` works only when each full pair would contain two identical characters.
6. Hex codes are useful for specifying and reusing precise colors in CSS.
