# Tree-structural Pseudo-classes in CSS

Tree-structural pseudo-classes let you select HTML elements according to their **position or relationship within the document tree**.

The document tree is the hierarchical structure formed by HTML elements. Elements are arranged as parents, children, and siblings:

- A **parent** contains other elements.
- A **child** is directly inside another element.
- **Siblings** share the same parent.

Tree-structural pseudo-classes are useful when you want to style elements based on where they appear, without adding extra classes to your HTML.

---

## 1. Overview

### Visual: The HTML document tree

![[01-HTML-document-tree.excalidraw]]

The main tree-structural pseudo-classes covered in this note are:

| Pseudo-class | What it selects |
|---|---|
| `:root` | The root element of the document |
| `:empty` | An element with no content |
| `:nth-child(n)` | An element at a particular position among all element siblings |
| `:nth-last-child(n)` | An element at a particular position when counting from the end |
| `:first-child` | The first child element of its parent |
| `:last-child` | The last child element of its parent |
| `:only-child` | An element that is its parent's only child |
| `:nth-of-type(n)` | An element at a particular position among siblings of the same element type |
| `:first-of-type` | The first sibling of its element type |
| `:last-of-type` | The last sibling of its element type |
| `:only-of-type` | An element that is the only sibling of its element type |

A useful distinction to remember throughout this topic is:

- **Child-based selectors** such as `:nth-child()` count an element's position among all element siblings.
- **Type-based selectors** such as `:nth-of-type()` count only siblings with the same HTML element type.

---

## 2. The `:root` Pseudo-class

The `:root` pseudo-class selects the **root element** of the document.

In an HTML document, the root element is normally `<html>`. Since it sits at the top of the document tree, styles applied to it can establish common styling for the page.

### Example: Styling the document root

```html
<link rel="stylesheet" href="styles.css" />

<h1>Welcome to My Website</h1>
<p>This is a sample paragraph to demonstrate the :root pseudo-class.</p>
```

```css
:root {
  background: black;
  color: aliceblue;
}
```

Here, `:root` selects the document's `<html>` element. The background and text color are set at the root level.

### Common use: Defining CSS custom properties

`:root` is also commonly used to define CSS custom properties (often called **CSS variables**).

```css
:root {
  --main-font: Arial, sans-serif;
  --primary-color: blue;
  --secondary-color: green;
}
```

Custom properties store reusable values. You can refer to them elsewhere in the stylesheet with `var()`:

```css
h1 {
  color: var(--primary-color);
}

body {
  font-family: var(--main-font);
}
```

**Why use `:root` for variables?**

Defining variables on `:root` makes them available throughout the document, so you can reuse shared colors, fonts, and other values instead of repeating them in multiple rules.

## 3. The `:empty` Pseudo-class

The `:empty` pseudo-class selects an element that has **no content**. It can be used to target empty elements and give them a special style or hide them.

For example, the following list contains two empty `<li>` elements:

```html
<link rel="stylesheet" href="styles.css" />

<ul>
  <li>Item 1</li>
  <li></li>
  <li>Item 2</li>
  <li></li>
  <li>Item 3</li>
</ul>
```

### Example: Styling empty elements

```css
:empty {
  background: black;
}
```

The selector matches the empty list items, allowing them to be styled differently from the items that contain text.

### Example: Hiding empty elements

A more practical use may be to hide empty elements so they do not take up space:

```css
:empty {
  display: none;
}
```

**When is this useful?**

- Hiding empty containers or list items.
- Applying a visual treatment to elements that have no content.
- Handling elements that may be left empty by dynamically generated HTML.

> **Important:** `:empty` is about whether an element has content, not whether it looks blank. An element containing text is not empty even if that text is invisible or consists of whitespace.

## 4. Selecting Elements by Position Among Siblings

Some pseudo-classes select elements according to their position among the children of the same parent.

### 4.1 `:nth-child(n)`

`:nth-child(n)` selects an element based on its position among **all element siblings**.

The `n` represents the position to match. Common values include:

- A number, such as `2`, to select the second child.
- `odd`, to select the first, third, fifth, and other odd-numbered children.
- `even`, to select the second, fourth, sixth, and other even-numbered children.

### 4.2 `:nth-last-child(n)`

`:nth-last-child(n)` works in a similar way, but counts positions **from the end** of the parent's children.

For example:

- `:nth-last-child(1)` selects the last child.
- `:nth-last-child(2)` selects the second-to-last child.

### Example: Alternating table row colors

The following HTML creates a simple fruit price table:

```html
<link rel="stylesheet" href="styles.css" />

<table>
  <tr>
    <th>Item</th>
    <th>Price</th>
  </tr>
  <tr>
    <td>Apple</td>
    <td>$1.00</td>
  </tr>
  <tr>
    <td>Banana</td>
    <td>$0.50</td>
  </tr>
  <tr>
    <td>Orange</td>
    <td>$0.80</td>
  </tr>
</table>
```

```css
th,
td {
  border: 1px solid lightgray;
  padding: 8px;
}

tr:nth-child(even) {
  background-color: orangered;
}

tr:nth-child(odd) {
  background-color: lightgreen;
}
```

The two selectors style table rows according to their position:

- `tr:nth-child(even)` selects even-positioned rows.
- `tr:nth-child(odd)` selects odd-positioned rows.

This creates alternating row colors, making the table easier to scan.

> **Remember:** `:nth-child()` counts all element siblings. It does not count only siblings that share the selected element's tag name. Compare it with `:nth-of-type()` below.

## 5. Selecting the First, Last, or Only Child

### Visual: Child positions

![[03-child-position-selectors.excalidraw]]

These pseudo-classes identify an element by its position or number of children within its parent.

### 5.1 `:first-child`

Selects an element if it is the **first child element** of its parent.

### 5.2 `:last-child`

Selects an element if it is the **last child element** of its parent.

### 5.3 `:only-child`

Selects an element if it is the **only child element** of its parent.

### Example: Styling the first and last list items

```html
<link rel="stylesheet" href="styles.css" />

<ul>
  <li>Item 1</li>
  <li>Item 2</li>
  <li>Item 3</li>
</ul>
```

```css
li:first-child {
  background-color: orangered;
}

li:last-child {
  background-color: lightgreen;
}
```

In this example:

- `li:first-child` selects `Item 1`.
- `li:last-child` selects `Item 3`.

If a page contains multiple unordered lists, these selectors are evaluated separately within each list. To target a particular list, make the selector more specific, for example:

```css
.menu li:first-child {
  background-color: orangered;
}
```

### Example: Selecting an element that is the only child

```html
<link rel="stylesheet" href="styles.css" />

<div class="container">
  <div>This is the only item in this container.</div>
</div>

<div class="container">
  <div>This is one of two items in this container.</div>
  <div>Here is the second item.</div>
</div>
```

```css
.container div:only-child {
  border: 2px solid crimson;
  padding: 10px;
  background-color: lightblue;
}
```

The selector `.container div:only-child` matches the `<div>` in the first container because it is that container's only child.

It does not match either `<div>` in the second container because that parent has two child elements.

## 6. Selecting Elements by Their Type

The `*-of-type` pseudo-classes work with an element's **HTML type** (its tag name).

For example, a `<p>` element is one type, while an `<h2>` element is another. These selectors count or identify an element among its siblings that have the same type.

This is different from the `*-child` pseudo-classes, which consider all element siblings.

### 6.1 `:first-of-type` and `:last-of-type`

- `:first-of-type` selects the first sibling of a particular element type within its parent.
- `:last-of-type` selects the last sibling of that element type within its parent.

### Example: Styling the first and last paragraphs

```html
<link rel="stylesheet" href="styles.css" />

<section>
  <h2>Introduction</h2>
  <p>This is the first paragraph in the first section.</p>
  <p>This is the second paragraph in the first section.</p>
</section>

<section>
  <h2>Details</h2>
  <p>This is the first paragraph in the second section.</p>
  <p>This is the second paragraph in the second section.</p>
</section>
```

```css
section p:first-of-type {
  background-color: lightgreen;
}

section p:last-of-type {
  background-color: lightblue;
}
```

Each `<section>` is a separate parent. Within each section:

- `p:first-of-type` selects the first `<p>` element.
- `p:last-of-type` selects the last `<p>` element.

The `<h2>` elements do not affect which paragraph is considered first or last because these selectors consider only siblings of the same type.

### 6.2 `:nth-of-type(n)`

`:nth-of-type(n)` selects an element according to its position among siblings of the **same element type**.

For example, `p:nth-of-type(2)` selects the second `<p>` sibling within its parent.

```html
<link rel="stylesheet" href="styles.css" />

<div class="container">
  <p>First paragraph</p>
  <p>Second paragraph</p>
  <p>Third paragraph</p>
</div>
```

```css
p:nth-of-type(2) {
  color: red;
  font-weight: bold;
}
```

The selector matches the second paragraph, so `Second paragraph` becomes red and bold.

### 6.3 `:only-of-type`

`:only-of-type` selects an element if it is the **only sibling of its type** within its parent.

Unlike `:only-child`, the parent may contain other element types. The selected element simply must be the only one of its own type.

### Example: Selecting the only paragraph in a container

```html
<link rel="stylesheet" href="styles.css" />

<div class="container">
  <p>The only paragraph</p>
</div>

<div class="container">
  <p>The first paragraph</p>
  <p>The second paragraph</p>
</div>
```

```css
p:only-of-type {
  border: 4px solid green;
}
```

The paragraph in the first container is selected because it is the only `<p>` inside that parent.

The paragraphs in the second container are not selected because they have another `<p>` sibling of the same type.

## 7. `*-child` vs. `*-of-type`

### Visual: How the two selector families count

![[02-nth-child-vs-nth-of-type.excalidraw]]

This is one of the most important distinctions in tree-structural pseudo-classes.

| Selector family | What it counts or checks |
|---|---|
| `:first-child`, `:last-child`, `:only-child`, `:nth-child()` | Position or number of an element among all element siblings |
| `:first-of-type`, `:last-of-type`, `:only-of-type`, `:nth-of-type()` | Position or number of an element among siblings with the same tag name |

Consider this HTML:

```html
<div class="container">
  <h2>Heading</h2>
  <p>First paragraph</p>
  <p>Second paragraph</p>
</div>
```

The first `<p>` is:

- **Not** the first child, because the `<h2>` comes before it.
- The first paragraph of its type, because it is the first `<p>` among its siblings.

Therefore:

```css
p:first-child {
  color: red;
}

p:first-of-type {
  color: green;
}
```

In this example, `p:first-child` does not match either paragraph, while `p:first-of-type` matches the first paragraph.

### Quick rule

> Use `*-child` when the position among all element siblings matters. Use `*-of-type` when the position among siblings of the same tag name matters.

## 8. Summary

| Pseudo-class | Meaning |
|---|---|
| `:root` | Selects the document's root element, usually `<html>` |
| `:empty` | Selects an element with no content |
| `:nth-child(n)` | Selects a position among all element siblings, counting from the beginning |
| `:nth-last-child(n)` | Selects a position among all element siblings, counting from the end |
| `:first-child` | Selects the first child element |
| `:last-child` | Selects the last child element |
| `:only-child` | Selects an element that is its parent's only child |
| `:nth-of-type(n)` | Selects a position among siblings of the same element type |
| `:first-of-type` | Selects the first sibling of the same element type |
| `:last-of-type` | Selects the last sibling of the same element type |
| `:only-of-type` | Selects an element that is the only sibling of its type |

## 9. Key Takeaways

- Tree-structural pseudo-classes select elements based on their position or relationship in the document tree.
- `:root` targets the root of the HTML document and is commonly used to define global CSS custom properties.
- `:empty` targets elements with no content.
- `:nth-child()` and `:nth-last-child()` select positions among all element siblings, counting from opposite ends.
- `:first-child`, `:last-child`, and `:only-child` identify the first, last, or only child of a parent.
- The `*-of-type` selectors count only siblings with the same element type.
- The most important distinction is **all siblings** (`*-child`) versus **same-type siblings** (`*-of-type`).
