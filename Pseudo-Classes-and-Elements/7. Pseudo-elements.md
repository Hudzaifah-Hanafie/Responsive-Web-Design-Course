# CSS Pseudo-elements

Pseudo-elements let CSS style a specific part of an element or generate content before or after its existing content. They are called *pseudo*-elements because they are not written as ordinary HTML elements in the document source.

They are useful when a visual detail belongs to an element but does not need its own HTML tag—for example, a decorative icon, an enlarged first letter, or a customized list marker.

## 1. What Is a Pseudo-element?

A pseudo-element represents a virtual part of an element. CSS can target that part as though it were a separate styling target, even though it is not an independently authored HTML element.

For example, a paragraph's first letter can be styled without wrapping that letter in a `<span>`. Likewise, CSS can add a decorative symbol before or after a button's text without changing the button's HTML.

The element to which the pseudo-element is attached is called the **originating element**.

> A pseudo-element is attached to an originating element. It cannot be selected or used as an independent HTML element in the source document.

### Pseudo-element syntax

Use a double colon (`::`) between the originating selector and the pseudo-element name:

```css
selector::pseudo-element {
  property: value;
}
```

The selector can be a type selector, class selector, ID selector, or another suitable selector.

For example:

```css
p::first-letter {
  font-size: 4rem;
}
```

The double colon distinguishes pseudo-elements from pseudo-classes, which use a single colon:

- `::before` — pseudo-element
- `:hover` — pseudo-class

The distinction is about what is being targeted: a pseudo-element targets a virtual part of an element, while a pseudo-class describes a state or condition of an element.

## 2. The `::before` and `::after` Pseudo-elements

`::before` and `::after` generate content at the beginning or end of an element's content.

- `::before` generates content immediately before the originating element's existing content.
- `::after` generates content immediately after the originating element's existing content.

They are often used for decorative details such as icons, labels, or visual indicators.

### How generated content works

The `content` property specifies what the pseudo-element displays. In the examples below, it inserts a star or an arrow.

The generated content can also be styled with CSS properties such as `font-size`, positioning, and `transition`.

### Example: add a star before button text

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<button class="cta-button">Learn More</button>
```

CSS:

```css
.cta-button {
  background-color: lightseagreen;
  color: white;
  border: none;
  padding: 10px 20px;
  cursor: pointer;
  position: relative;
}

.cta-button::before {
  content: "⭐";
  position: absolute;
  left: 3px;
  top: 8px;
  font-size: 0.75rem;
}
```

**What is happening?**

1. `.cta-button` selects the button.
2. `::before` creates a pseudo-element before the button's original text.
3. `content: "⭐"` supplies the star character to display.
4. `position: absolute`, `left`, and `top` place the star at a specific position within the button's positioning context.

The example sets `position: relative` on the button and `position: absolute` on the pseudo-element. This establishes the button as the positioning reference for the star. Absolute positioning is a separate CSS topic and is introduced here only to demonstrate placement.

### Example: add an arrow after button text

The same button can use `::after` to add an arrow at the end of its content.

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<button class="cta-button">Learn More</button>
```

CSS:

```css
.cta-button {
  background-color: orange;
  border: none;
  padding: 10px 30px;
  cursor: pointer;
  position: relative;
}

.cta-button::after {
  content: '➡️';
  position: absolute;
  right: 5px;
  bottom: 6px;
  font-size: 1.125rem;
  transition: transform 0.3s ease;
}
```

Here:

- `content: '➡️'` inserts an arrow after the button's original content.
- `position: absolute` with `right` and `bottom` places the arrow near the button's lower-right corner.
- `transition: transform 0.3s ease` makes changes to the `transform` property animate smoothly over 0.3 seconds.

The `transition` property does not move the arrow by itself. It controls how a change to `transform` is animated.

### Combine a pseudo-element with a pseudo-class

A pseudo-class can be used together with a pseudo-element. This lets CSS style the generated content when the originating element enters a particular state.

```html
<link rel="stylesheet" href="styles.css" />
<button class="cta-button">Learn More</button>
```

```css
.cta-button {
  background-color: orange;
  border: none;
  padding: 10px 30px;
  cursor: pointer;
  position: relative;
}

.cta-button::after {
  content: "➡️";
  position: absolute;
  right: 5px;
  bottom: 6px;
  font-size: 1.125rem;
  transition: transform 0.3s ease;
}

.cta-button:hover::after {
  transform: translateX(2px);
}
```

When the pointer hovers over the button:

1. `.cta-button:hover` matches the button in its hover state.
2. `::after` targets the arrow generated after the button's content.
3. `transform: translateX(2px)` moves that generated arrow 2 pixels to the right.
4. The `transition` declared on `::after` makes the movement take place smoothly over 0.3 seconds.

**Important distinction:** `:hover` describes the button's state; `::after` identifies the generated content being styled. They work together in `.cta-button:hover::after`.

The `transform` property can translate (move), rotate, scale, or skew an element. This example uses only translation along the horizontal axis.

## 3. The `::first-letter` Pseudo-element

`::first-letter` targets the first letter of an element's content. It allows that letter to receive its own styling without adding a wrapper element to the HTML.

### Example: enlarge the first letter of a paragraph

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<p>freeCodeCamp lets you learn to code without having to pay.</p>
```

CSS:

```css
p::first-letter {
  font-size: 4rem;
}
```

The selector targets the first letter of each matching paragraph. The `font-size: 4rem` declaration makes that letter much larger than the surrounding text.

This technique is commonly associated with a *drop cap*—an enlarged first letter at the beginning of a paragraph.

## 4. The `::marker` Pseudo-element

`::marker` targets the marker of a list item: the bullet in an unordered list or the number (or other marker) in an ordered list.

It lets you customize list markers so that they fit the visual style or color scheme of a website.

### Example: style list markers

HTML:

```html
<link rel="stylesheet" href="styles.css" />
<ul>
  <li>Unordered list item 1</li>
  <li>Unordered list item 2</li>
  <li>Unordered list item 3</li>
  <li>Unordered list item 4</li>
</ul>

<ol>
  <li>Ordered list item 1</li>
  <li>Ordered list item 2</li>
  <li>Ordered list item 3</li>
  <li>Ordered list item 4</li>
</ol>
```

CSS:

```css
li::marker {
  color: crimson;
  font-size: 1.5em;
  font-weight: bold;
}
```

The selector `li::marker` targets the marker belonging to each list item. The declarations:

- set the marker color to crimson;
- increase its size to `1.5em`;
- make it bold.

The rule applies to the markers in both the unordered and ordered lists.

## 5. Other Pseudo-elements to Explore

This lesson focuses on a few commonly encountered pseudo-elements. The original material also points to these examples for further exploration:

| Pseudo-element     | General purpose                                                              |
| ------------------ | ---------------------------------------------------------------------------- |
| `::placeholder`    | Targets placeholder text in a form control.                                  |
| `::spelling-error` | Targets text identified by the browser as a spelling error, where supported. |
| `::selection`      | Targets the portion of text selected by the user.                            |

Browser support and the styling rules available can vary between pseudo-elements, so consult current documentation when using less familiar ones.

## 6. Quick Reference

| Pseudo-element     | What it targets or does                                    | Example              |
| ------------------ | ---------------------------------------------------------- | -------------------- |
| `::before`         | Generates content before the originating element's content | `.button::before`    |
| `::after`          | Generates content after the originating element's content  | `.button::after`     |
| `::first-letter`   | Targets the first letter of an element's content           | `p::first-letter`    |
| `::marker`         | Targets a list item's bullet or numbering                  | `li::marker`         |
| `::placeholder`    | Targets placeholder text in a form control                 | `input::placeholder` |
| `::spelling-error` | Targets spelling-error text where supported                | `p::spelling-error`  |
| `::selection`      | Targets text selected by the user                          | `p::selection`       |

## Summary

- A **pseudo-element** targets a virtual part of an element or generates content without requiring an extra HTML element.
- Pseudo-elements are attached to an **originating element** and are written with a double colon (`::`).
- `::before` and `::after` generate content before and after the originating element's existing content. The `content` property supplies that content.
- Generated content can be styled with CSS, just like the examples' positioning, font sizing, and transitions.
- A pseudo-class such as `:hover` can be combined with a pseudo-element, as in `.cta-button:hover::after`.
- `::first-letter` targets the first letter of an element's content.
- `::marker` targets the bullet or numbering of a list item.

## Key Takeaways

1. **Double colon means pseudo-element.** Remember the distinction between `::before` and `:hover`.
2. **`::before` and `::after` are useful for visual additions.** They can add decorative content without changing the HTML markup.
3. **The `content` property matters for generated content.** It specifies what `::before` or `::after` displays.
4. **Pseudo-elements can be styled and animated.** The arrow example combines `transform` with `transition`.
5. **Choose the pseudo-element based on the part you want to target.** Use `::first-letter` for a paragraph's first letter and `::marker` for list bullets or numbering.
