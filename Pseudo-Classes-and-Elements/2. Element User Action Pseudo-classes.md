# CSS User Action Pseudo-Classes

User action pseudo-classes let CSS respond to a user's interaction with a webpage. They make interactive elements provide visual feedback—for example, changing a button's appearance when the pointer moves over it or showing which form field currently has keyboard focus.

These visual cues help users understand the current state of an element and make a website easier to use.

## 1. What Are User Action Pseudo-Classes?

A **pseudo-class** is a CSS keyword added to a selector to target an element in a particular state.

User action pseudo-classes target states related to user interaction. They allow you to change an element's appearance **without JavaScript**.

For example:

```css
button:hover {
  background-color: darkgreen;
}
```

This rule applies while the user hovers over a button.

The colon (`:`) introduces the pseudo-class. In `button:hover`:

- `button` is the element selector.
- `:hover` is the pseudo-class that describes the element's current state.

## 2. Common User Action Pseudo-Classes

### `:hover` — Pointer Is Over an Element

The `:hover` pseudo-class applies when the user places a mouse or other pointing device over an element.

It is commonly used to provide visual feedback for buttons, links, and other interactive elements.

**HTML:**

```html
<link rel="stylesheet" href="styles.css" />

<button class="btn">Hover Over Me</button>
```

**CSS:**

```css
.btn:hover {
  background-color: darkgreen;
  color: white;
  cursor: pointer;
}
```

When the pointer moves over the button:

- Its background changes to dark green.
- Its text becomes white.
- The cursor changes to a pointer.

When the pointer moves away, the `:hover` styles no longer apply.

### `:active` — Element Is Being Activated

The `:active` pseudo-class applies while an element is being activated by the user—for example, during the moment a link or button is being pressed.

It provides immediate feedback that the interaction is being registered.

**HTML:**

```html
<link rel="stylesheet" href="styles.css" />

<a href="#">Example link</a>
```

**CSS:**

```css
a:active {
  color: crimson;
}
```

While the user presses the link, its text becomes crimson. The style stops applying when the activation ends.

### `:focus` — Element Has Focus

The `:focus` pseudo-class applies when an element receives focus. This commonly happens when a user:

- Selects a form field with a mouse or other pointing device.
- Navigates to an interactive element using the keyboard, such as with the `Tab` key.

Focus styling is especially important for **keyboard accessibility**. It helps users identify which element will receive their next keyboard interaction.

**HTML:**

```html
<link rel="stylesheet" href="styles.css" />

<form>
  <input type="text" />
</form>
```

**CSS:**

```css
input:focus {
  outline: 2px solid darkgreen;
  border-radius: 4px;
}
```

When the input receives focus, a dark-green outline appears around it.

> **Accessibility note:** Keep a visible focus indicator. Removing or hiding focus styles can make keyboard navigation difficult.

### `:visited` — Link Has Been Visited

The `:visited` pseudo-class targets links that the browser recognizes as previously visited by the user.

It can help users distinguish links they have already opened from links they have not visited.

**HTML:**

```html
<link rel="stylesheet" href="styles.css" />

<a href="https://www.example.com" target="_blank">Visit Example.com</a>
```

**CSS:**

```css
a:visited {
  color: cyan;
}
```

After the browser records the link as visited, its text can appear cyan.

### `:checked` — Checkbox or Radio Button Is Selected

The `:checked` pseudo-class targets form controls that are currently selected, such as:

- A checkbox that has been checked.
- A radio button that has been selected.

It is useful when you want to customize the appearance of selected form controls.

The following example creates a custom checkbox for agreeing to a website's terms.

**HTML:**

```html
<link rel="stylesheet" href="styles.css" />

<form>
  <label>
    Agree <input class="checkbox" type="checkbox" />
  </label>
</form>
```

**CSS:**

```css
.checkbox {
  appearance: none;
  width: 18px;
  height: 18px;
  border: 2px solid #ccc;
  border-radius: 4px;
  display: inline-block;
  position: relative;
  cursor: pointer;
  transition: all 0.25s ease;
  vertical-align: middle;
}

.checkbox:hover {
  border-color: #888;
}

.checkbox:checked {
  background-color: #4caf50;
  border-color: #4caf50;
}

.checkbox:checked::after {
  content: "";
  position: absolute;
  left: 4px;
  top: 0px;
  width: 5px;
  height: 10px;
  border: solid white;
  border-width: 0 2px 2px 0;
  transform: rotate(45deg);
}

.checkbox:focus {
  outline: 2px solid #90caf9;
  outline-offset: 2px;
}
```

**How the example works:**

1. `appearance: none` removes the browser's default visual styling for the checkbox.
2. The base `.checkbox` rule defines the custom checkbox's size, border, and shape.
3. `.checkbox:hover` changes the border color when the pointer is over the checkbox.
4. `.checkbox:checked` changes the background and border when the checkbox is selected.
5. `.checkbox:checked::after` creates a checkmark using a pseudo-element. The border is rotated to form the check shape.
6. `.checkbox:focus` adds an outline when the checkbox receives focus.

> **Note:** This example uses properties such as `appearance`, `::after`, and `transform` that may be covered in later lessons. You do not need to understand every property yet to understand the role of `:checked`: it lets CSS apply styles when the checkbox is selected.

## 3. Other Useful Action-Related Pseudo-Classes

The following pseudo-classes are also useful when styling interactive elements and form controls.

### `:focus-within` — An Element or Its Descendant Has Focus

Targets an element when **itself or any element inside it** has focus.

This is useful when you want to style a whole form group or container while one of its input fields is focused.

### `:enabled` — Form Control Is Enabled

Targets form controls that are currently enabled and available for interaction.

### `:disabled` — Form Control Is Disabled

Targets form controls that are currently disabled and generally cannot be interacted with.

### `:target` — Element Matches the URL Fragment

Targets an element whose `id` matches the fragment identifier in the current URL—the part after the `#` symbol.

For example, in a URL such as `https://example.com/page#contact`, the element with `id="contact"` is the target.

## 4. Comparing the Main Pseudo-Classes

| Pseudo-class    | When it applies                                             | Typical use                                          |
| --------------- | ----------------------------------------------------------- | ---------------------------------------------------- |
| `:hover`        | The pointer is over an element.                             | Highlight a button or link.                          |
| `:active`       | An element is being activated, such as while it is pressed. | Show immediate press feedback.                       |
| `:focus`        | An element has keyboard or pointer focus.                   | Show which control is currently focused.             |
| `:visited`      | A link has been visited.                                    | Distinguish previously visited links.                |
| `:checked`      | A checkbox or radio button is selected.                     | Change the appearance of selected controls.          |
| `:focus-within` | An element or one of its descendants has focus.             | Highlight a form group containing the focused input. |
| `:enabled`      | A form control is enabled.                                  | Style controls that are available for interaction.   |
| `:disabled`     | A form control is disabled.                                 | Visually distinguish unavailable controls.           |
| `:target`       | An element matches the URL fragment.                        | Highlight the section linked to by a URL fragment.   |

## 5. Mental Model: Style Elements Based on Their State

Think of these pseudo-classes as **state checks**. CSS selects an element when its current state matches the pseudo-class.

```text
User or browser interaction
          |
          v
    Element state
          |
          v
  CSS pseudo-class matches
          |
          v
  Matching CSS styles apply
```

For example:

- Pointer moves over a button → `:hover` matches.
- User presses a link → `:active` matches.
- User tabs to an input → `:focus` matches.
- User checks a checkbox → `:checked` matches.

The important idea is that you do not need to add or remove a class with JavaScript for these built-in interaction states. CSS can respond to them directly.

## Summary

- **User action pseudo-classes** let CSS style elements according to interaction-related states.
- `:hover` responds to pointer hover.
- `:active` responds while an element is being activated.
- `:focus` identifies the element that currently has focus and is important for keyboard accessibility.
- `:visited` identifies previously visited links.
- `:checked` identifies selected checkboxes and radio buttons.
- `:focus-within`, `:enabled`, `:disabled`, and `:target` cover other useful focus, form-control, and URL-fragment states.

## Key Takeaways

1. A pseudo-class is written with a colon after a selector, such as `button:hover`.
2. Pseudo-classes let CSS respond to an element's state without requiring JavaScript.
3. Use interaction feedback to help users understand what is happening on a page.
4. Keep focus indicators visible so keyboard users can identify the currently focused element.
5. Use `:checked` to style selected checkboxes and radio buttons, and `:disabled` or `:enabled` to distinguish form controls by availability.
