# CSS Location Pseudo-classes

Location pseudo-classes let you style links and elements according to their relationship with the current document or the current URL.

For example, you can use them to:

- Give unvisited and visited links different colors.
- Apply the same style to all links, regardless of their visited state.
- Distinguish links that point to the current document from other links.
- Highlight the section a user has navigated to through an in-page link.

The location pseudo-classes covered in this note are:

| Pseudo-class | What it selects |
|---|---|
| `:link` | Unvisited links |
| `:visited` | Visited links |
| `:any-link` | Links whether visited or unvisited |
| `:local-link` | Links that point to the same document |
| `:target` | The element identified by the current URL fragment |

---

## 1. `:link` — Unvisited Links

The `:link` pseudo-class selects links that the user has **not visited**.

Use it when you want unvisited links to have a particular appearance. For example, you might give them your website's primary color.

### Example

HTML:

```html
<link rel="stylesheet" href="styles.css" />

<a target="_blank" href="https://www.example.com">Visit Example.com</a>
```

CSS:

```css
a:link {
  color: magenta;
}
```

In this example, the link appears magenta while it is unvisited.

Once the browser considers the destination visited, the `:link` style no longer applies to that link. The `:visited` pseudo-class can then be used to style it differently.

---

## 2. `:visited` — Visited Links

The `:visited` pseudo-class selects links that the user has **already visited**.

It is commonly used alongside `:link` to make visited and unvisited links visually distinct.

### Example

HTML:

```html
<link rel="stylesheet" href="styles.css" />

<a target="_blank" href="https://www.example.com">Visit Example.com</a>
```

CSS:

```css
a:visited {
  color: purple;
}
```

After the link has been visited, it can appear purple instead of using the unvisited-link style.

### Why It Matters

Showing visited links differently helps users recognize which pages they have already opened. This can make it easier to navigate a website or return to information they have not read yet.

---

## 3. `:any-link` — All Links

The `:any-link` pseudo-class selects a link whether it is **visited or unvisited**.

It combines the matching behavior of `:link` and `:visited`. This is useful when you want to apply one shared style to every link without writing separate rules for the two visited states.

### Example

HTML:

```html
<link rel="stylesheet" href="styles.css" />

<a target="_blank" href="https://www.example.com">Visit Example.com</a>
```

CSS:

```css
a:any-link {
  color: crimson;
}
```

Both visited and unvisited links matching this selector receive the crimson color.

### Quick Comparison

| Selector | Matches |
|---|---|
| `a:link` | Unvisited links |
| `a:visited` | Visited links |
| `a:any-link` | Both visited and unvisited links |

> **Remember:** Use `:any-link` when the visited state does not matter and you want to style links consistently.

---

## 4. `:local-link` — Links to the Same Document

The `:local-link` pseudo-class is intended to select links that point to the **same document**.

It can be useful when you want to distinguish links to the current document from links to other documents or pages.

For example, a site could use different styles for links that stay within the current document and links that lead elsewhere.

> **Browser support:** The source material states that no browser currently supports `:local-link`. Check current browser compatibility before relying on it in a project.

---

## 5. `:target` — The Element Identified by the URL Fragment

The `:target` pseudo-class selects the element whose `id` matches the **fragment identifier** in the current URL.

A fragment identifier is the part of a URL that follows the `#` symbol.

For example:

```text
https://www.example.com/page#section1
```

Here, `#section1` identifies the element with `id="section1"`.

This is especially useful for pages with in-page navigation, such as a table of contents. When a user follows a link to a section, CSS can highlight the section they have navigated to.

### Example: Highlighting the Current Section

HTML:

```html
<link rel="stylesheet" href="styles.css" />

<nav id="table-of-contents">
  <ul>
    <li><a href="#section1">Introduction</a></li>
    <li><a href="#section2">Features</a></li>
  </ul>
</nav>

<section id="section1">
  <h2>Introduction</h2>
  <p>This is the introduction section.</p>
</section>

<section id="section2">
  <h2>Features</h2>
  <p>This section describes the features.</p>
</section>
```

CSS:

```css
section:target {
  background-color: green;
  border: 2px solid green;
  padding: 10px;
}
```

### How It Works

1. The navigation contains links to `#section1` and `#section2`.
2. Each link points to an element with a matching `id`.
3. When the user clicks a link, the browser navigates to that fragment.
4. The matching section becomes the current target.
5. The `section:target` rule applies to that section, giving it a green background, green border, and `10px` of padding.

For example:

- Clicking **Introduction** targets `<section id="section1">`.
- Clicking **Features** targets `<section id="section2">`.

Only the section matching the current URL fragment receives the `:target` styling.

---

## Summary

| Pseudo-class | Purpose | Typical use |
|---|---|---|
| `:link` | Selects unvisited links | Set the default appearance of unvisited links |
| `:visited` | Selects visited links | Show users which links they have already opened |
| `:any-link` | Selects visited and unvisited links | Apply a shared style to all links |
| `:local-link` | Selects links pointing to the same document | Distinguish same-document links from other links |
| `:target` | Selects the element matching the URL fragment | Highlight a section reached through in-page navigation |

## Key Takeaways

- **`:link`** styles links that have not been visited.
- **`:visited`** styles links that have been visited.
- **`:any-link`** matches both visited and unvisited links.
- **`:local-link`** is intended for links that point to the same document, but the source material notes that it is not supported by browsers.
- **`:target`** selects the element whose `id` matches the fragment in the current URL.
- `:target` is particularly useful for highlighting sections in pages with in-page navigation.

## Mental Model

Think of these pseudo-classes as answering two different questions:

1. **What is the link's relationship to browsing history or the current document?**
   - `:link` — Has not been visited.
   - `:visited` — Has been visited.
   - `:any-link` — Is a link, regardless of visited state.
   - `:local-link` — Points to the same document.

2. **Which element is the current URL pointing to?**
   - `:target` — The element whose `id` matches the URL fragment.

In short, the first group helps style links based on their state or destination, while `:target` helps style the element currently addressed by an in-page URL fragment.
