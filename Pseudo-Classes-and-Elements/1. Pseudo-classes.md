# CSS Pseudo-classes

CSS pseudo-classes let you style an element according to its **state** or **position in the document**. They make it possible to respond visually to user interactions and target particular elements without adding extra classes to the HTML.

For example, a button can change appearance while it is being clicked, a link can look different after it has been visited, and the first item in a list can have different spacing from the others.

---

## 1. How Pseudo-classes Work

A pseudo-class is a keyword added to a CSS selector with a colon (`:`).

```css
selector:pseudo-class {
  /* CSS properties */
}
```

- `selector` identifies the element or elements you want to target.
- `:` introduces the pseudo-class.
- `pseudo-class` specifies the state or position that the element must match.

For example:

```css
button:hover {
  background-color: crimson;
}
```

This selects a `button` only while the pointer is hovering over it.

> **Remember:** A pseudo-class does not create a new HTML element. It describes a condition that an existing element must meet for the CSS rule to apply.

---

## 2. Pseudo-classes for User Interaction and Element State

Some pseudo-classes apply when a user interacts with an element or when the element has a particular state.

### `:active` — While an Element Is Being Activated

The `:active` pseudo-class selects an element while it is being activated. For a button, this commonly means the period while the user is pressing it.

```html
<link rel="stylesheet" href="styles.css" />

<button>Example Button</button>
```

```css
button:active {
  background: greenyellow;
}
```

**What happens:** The button's background becomes green-yellow while it is being pressed.

**When to use it:** Use `:active` to provide immediate visual feedback during a click or other activation.

### `:hover` — While the Pointer Is Over an Element

The `:hover` pseudo-class selects an element while the user's pointer is over it.

```html
<link rel="stylesheet" href="styles.css" />

<a href="#">Hover over me!</a>
```

```css
a:hover {
  text-decoration: none;
  color: white;
  background: crimson;
}
```

**What happens:** When the pointer moves over the link, its text becomes white, its background becomes crimson, and its underline is removed.

**When to use it:** Use `:hover` to make links, buttons, cards, and other elements respond visually to pointer movement.

### `:focus` — When an Element Has Focus

The `:focus` pseudo-class is another commonly used interaction pseudo-class. It selects an element when it has focus, such as when a user selects a form field or navigates to a control with the keyboard.

```css
input:focus {
  outline: 2px solid royalblue;
}
```

This example adds a visible outline to an input while it has focus.

> **Practical note:** Keep a clear focus indicator so keyboard users can tell which control they are currently interacting with.

### `:visited` — Links the User Has Already Visited

The `:visited` pseudo-class selects a link whose destination the browser recognizes as having been visited.

```html
<link rel="stylesheet" href="styles.css" />

<a href="https://www.example.com" target="_blank">Visit Example.com</a>
```

```css
a:visited {
  color: purple;
}
```

**What happens:** After the browser records the link as visited, it can display the link in purple.

**When to use it:** Use `:visited` when you want visited links to look different from links the user has not visited.

### `:disabled` — When a Form Control Is Disabled

The `:disabled` pseudo-class selects a form control that is disabled.

```html
<link rel="stylesheet" href="styles.css" />

<button disabled>Disabled Button</button>
```

```css
button:disabled {
  background-color: lightgray;
}
```

**What happens:** The disabled button receives a light-gray background.

The `disabled` HTML attribute makes the button disabled; the `:disabled` pseudo-class lets CSS style it based on that state.

### `:enabled` — When a Form Control Is Enabled

`:enabled` is the counterpart to `:disabled`. It selects form controls that are enabled.

```css
button:enabled {
  cursor: pointer;
}
```

This example applies a pointer cursor to enabled buttons.

### `:checked` — When a Checkbox or Radio Button Is Selected

The `:checked` pseudo-class selects a checkbox, radio button, or other checkable input when it is selected.

```css
input:checked {
  accent-color: seagreen;
}
```

This example changes the accent color of a checked input.

### `:required` — When a Form Field Is Required

The `:required` pseudo-class selects a form control that has the `required` attribute.

```html
<input type="email" required />
```

```css
input:required {
  border: 1px solid crimson;
}
```

The HTML attribute makes the field required; the pseudo-class allows CSS to identify and style it.

## 3. Pseudo-classes for an Element's Position

Other pseudo-classes select elements according to their position or relationship with other elements.

Consider this HTML:

```html
<link rel="stylesheet" href="styles.css" />

<div class="container">
  <p>first child</p>
  <p>second child</p>
  <p>third child</p>
  <p>last child</p>
</div>
```

The four paragraphs are children of the `div.container` element.

### `:first-child` — The First Child

The `:first-child` pseudo-class selects an element only if it is the first child of its parent.

```css
.container p:first-child {
  background: lightcoral;
  padding: 0.4rem;
}
```

**What happens:** The first paragraph receives a light-coral background and `0.4rem` of padding on all four sides.

**Important:** `:first-child` checks the element's position among *all* of its parent's element children. It does not simply mean “the first element of this tag type.”

For example, if a `div` contains a heading before its first paragraph, that paragraph is not the `:first-child`.

### `:last-child` — The Last Child

The `:last-child` pseudo-class selects an element only if it is the last child of its parent.

```css
.container p:last-child {
  background: lightcoral;
  padding: 0.4rem;
}
```

**What happens:** The last paragraph receives a light-coral background and `0.4rem` of padding.

As with `:first-child`, the position is checked among all element children of the parent.

### `:first-of-type` — The First Element of Its Type

`:first-of-type` selects the first sibling of a particular element type.

For example:

```css
.container p:first-of-type {
  font-weight: bold;
}
```

This selects the first `p` among the siblings, even if another element type appears before it.

### `:last-of-type` — The Last Element of Its Type

`:last-of-type` selects the last sibling of a particular element type.

```css
.container p:last-of-type {
  font-style: italic;
}
```

This selects the last `p` among the siblings, regardless of whether other element types appear before or after it.

### `:nth-of-type()` — An Element of a Particular Type by Position

`:nth-of-type()` selects an element according to its position among siblings of the same element type.

```css
.container p:nth-of-type(2) {
  color: crimson;
}
```

This selects the second `p` element among its siblings.

---

## 4. Another Pseudo-class: `:modal`

The `:modal` pseudo-class selects an element that is currently in a modal state. For example, a dialog opened modally with the appropriate browser API can match this pseudo-class.

```css
dialog:modal {
  border: 2px solid royalblue;
}
```

This rule styles a `dialog` element while it is displayed in the browser's modal state.

---

## 5. Comparing Common Pseudo-classes

The following table summarizes the pseudo-classes introduced in this note.

| Pseudo-class | What it selects |
|---|---|
| `:active` | An element while it is being activated |
| `:hover` | An element while the pointer is over it |
| `:focus` | An element that currently has focus |
| `:visited` | A link the browser recognizes as visited |
| `:disabled` | A disabled form control |
| `:enabled` | An enabled form control |
| `:checked` | A selected checkbox, radio button, or checkable input |
| `:required` | A form control with the `required` attribute |
| `:first-child` | An element that is the first child of its parent |
| `:last-child` | An element that is the last child of its parent |
| `:first-of-type` | The first sibling of its element type |
| `:last-of-type` | The last sibling of its element type |
| `:nth-of-type()` | A sibling of a particular element type at a specified position |
| `:modal` | An element currently in a modal state |

---

## 6. Key Differences to Remember

### `:first-child` vs. `:first-of-type`

These two pseudo-classes may look similar, but they check different things:

- `:first-child` checks whether the element is the **first child of any element type**.
- `:first-of-type` checks whether the element is the **first sibling of its own element type**.

For example:

```html
<div class="container">
  <h2>Heading</h2>
  <p>First paragraph</p>
  <p>Second paragraph</p>
</div>
```

```css
p:first-child {
  color: red;
}

p:first-of-type {
  color: green;
}
```

The paragraph does not match `p:first-child`, because the heading comes first. It does match `p:first-of-type`, because it is the first paragraph among its siblings.

### `:disabled` vs. `:enabled`

- `:disabled` selects controls that are disabled.
- `:enabled` selects controls that are enabled.

These pseudo-classes let you give users different visual cues depending on whether a control can currently be used.

---

## Summary

Pseudo-classes extend CSS selectors by allowing styles to depend on an element's state or position.

| Category | Examples | Typical purpose |
|---|---|---|
| User interaction | `:hover`, `:active`, `:focus` | Respond to pointer, click, or keyboard interaction |
| Link state | `:visited` | Distinguish links the user has visited |
| Form state | `:disabled`, `:enabled`, `:checked`, `:required` | Reflect a form control's current state or requirements |
| Child position | `:first-child`, `:last-child` | Target the first or last child of a parent |
| Element type and position | `:first-of-type`, `:last-of-type`, `:nth-of-type()` | Target elements by position among siblings of the same type |
| Modal state | `:modal` | Style an element while it is in a modal state |

## Key Takeaways

- A **pseudo-class** is added to a selector using a colon (`:`), followed by the pseudo-class name.
- Pseudo-classes select elements based on a condition, such as interaction state, form state, or position in the document.
- `:hover`, `:active`, and `:focus` are useful for providing visual feedback during interaction.
- `:disabled`, `:enabled`, `:checked`, and `:required` help style form controls according to their state.
- `:first-child` and `:last-child` check an element's position among all its parent's element children.
- `:first-of-type`, `:last-of-type`, and `:nth-of-type()` check position among siblings of the same element type.
- Pseudo-classes let you style elements based on their state or structure without adding extra classes to the HTML.

## Mental Model

Think of a pseudo-class as an **extra condition attached to a CSS selector**:

```text
CSS selector
    |
    v
Does the element match the pseudo-class condition?
    |
    +-- Yes --> Apply the CSS declarations
    |
    +-- No  --> Do not apply this rule
```

For example, `button:hover` can be read as:

> Select a `button`, but only while the pointer is hovering over it.
